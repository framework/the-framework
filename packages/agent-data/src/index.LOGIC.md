The package's entry point: one import gives a consumer the two names (`.branches` and `agent-data`), the git runner with its time budgets and its two readings of a failure, the writer of git's own ignore rule, every operation on a branch used as a file store: its checkout, the write cycle, the pull, the reads from anywhere, the one-shot write, taking the branch off this machine, and the sharing setting that decides whether the branch leaves the machine (its name, its read, its write, forgetting it, and how far the branch reaches); and the provider lookup: a project's installed packages, which one provides a kind of OpenAgent's data, and how its command is run. The four skill packages (`skill-branches`, `skill-tickets`, `skill-queue`, `skill-logs`) and the product (`packages/openagent`) import from here; no skill imports another skill, since this library is what they share. A second entry point, `names`, exposes only the two names, for code that must not load Node modules such as the dashboard.
