The package's public entry point: the Claude Code driver with its driver session, its output parser and its option types (the permission mode, MCP servers, and the person's own setup as an option, whose type is exported by `agent-driver`), the readiness check for Claude Code, the quota reader and its readout parser from `claude-code-quota.ts`, and the GitHub Actions driver with its driver session, its transcript replay and its fetch seam. The zip reader in `actions-zip.ts` is deliberately not exported: it is an implementation detail of the GitHub Actions driver, not product API.
