The package's public entry point: the Claude Code driver with its driver session, its output parser (which `@openagt/agent-driver-github-actions` also reads a runner's transcript with) and its option types (the permission mode, MCP servers, and the person's own setup as an option, whose type is exported by `@openagt/agent-driver`), the readiness check for Claude Code, the quota reader and its readout parser from `claude-code-quota.ts`, and the model lister and its answer parser from `claude-code-models.ts`.
