The package's public entry point: everything a caller (the runner in `packages/agent-runner`, the scheduler in `packages/agent-scheduler`, the product in `packages/framework`) may import. That is the contract's vocabulary from `types.ts` with its transient-reason rule, the Claude Code, Codex, GitHub Actions and fake drivers with their output parsers and option types, the quota reader and its readout parser from `claude-code-quota.ts`, the readiness check from `ready.ts` (is a coding agent's CLI installed and logged in) with the real CLI probe it uses, the session log (with its card and diary file names, its diary line, and `DIARY_ENV` (`AGENT_DIARY`) with the rule that puts the diary's path in the agent's environment), the progress-event reporter a driver implemented outside this package builds on, and the process core of `cli-session.ts` with its parser and spawn seams. The zip reader in `actions-zip.ts` is deliberately not exported: it is an implementation detail of the GitHub Actions driver, not product API.
