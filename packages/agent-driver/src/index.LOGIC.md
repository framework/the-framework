The package's public entry point: everything a caller (the product's agent lifecycle in `packages/framework`) may import. That is the contract's vocabulary from `types.ts` with its transient-reason rule, the Claude Code, Codex, GitHub Actions and fake drivers with their output parsers and option types, the quota reader and its readout parser from `claude-code-quota.ts`, the progress-event reporter a driver implemented outside this package builds on (the `claude-web` driver in `packages/framework/src/driver/cloud.ts` does), and the process core of `cli-session.ts` with its parser and spawn seams. The zip reader in `actions-zip.ts` is deliberately not exported: it is an implementation detail of the GitHub Actions driver, not product API.
