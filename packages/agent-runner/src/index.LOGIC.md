The entry point: re-exports everything a program imports from the package, the scheduler among them: the names (the config file `config.yml` among them), the reading of that file and its `personal:` parts, the run records and markers with the tool's mark, the publish levels (`commit`, `branch`, `pr`, `merge`) with the check that a word is one, one run and its resume with the run's id rule, the sentence a run adds after each of its agent's prompts (the one each publish level adds, and the one a follow-up adds in its place), the sweep, the line a run's parent is told and its delivery, the processes (a run and a resume of the real project, the detached run and its spawn, the detached continuation, the way an ended parent is continued, whether a run can start here, the coding agents and their names, the `AGENT_ID` environment name), the probe of a live pid, the run's lock path and the spawned run's stderr path (`run-lock.ts`), the project's git host (a branch's pull request, a merge), the live record, the dashboard's hooks writer (`init`, and the writer another tool's `init` uses) and the command line. No rule of its own.
