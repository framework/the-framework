What the tests cover, the line and its delivery on their own, then whole runs against a real repository with an origin and an `agent-data` branch, the agents faked and the continuation of an ended parent kept instead of spawned:

- **The line** - a done run with a branch, a pull request and last words; a failed run with its detail and nothing else; a waiting run with its question on one line, its branch, and no last words when they are blank.
- **Delivery** - a working parent gets the line in its inbox and is not continued; an ended parent is continued with the line and its inbox stays empty; a parent that ends while the line is on its way is continued with everything left in its inbox, a person's answer as an answer and before the line; a continuation that fails is one line on the log and nothing is thrown.
- **A run started for a working parent, from the parent's branch** - the parent commits a file on its own branch without pushing it and starts a child with that branch as the base; the child's checkout holds the file; the child's record names the parent and the base in the tool's mark; the child's end, naming the branch its own commit is on and its last words, is the prompt of the parent's next turn in the same run.
- **A run whose parent has ended** - a child that ends waiting continues its parent with the question, its branch and its last words; answered, the same child ends done, its record still names the parent, and the parent is continued again, with no branch named since the child's empty branch went with its checkout; a child whose base does not exist is recorded failed and its parent told `could not create a checkout: …`; a run with no parent continues nobody.
