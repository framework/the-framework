The executable behind `npx agent-scheduler`, and the process the tool spawns for its own scheduler and for each run: it hands the shell's arguments, the current directory and the two output streams to the command line in `src/cli.ts`, and exits with the code it answers: 0 for a result, 1 for a refusal or a failure, 2 for a command line that could not be read. A failure the command line did not catch is printed to stderr and exits 1.
