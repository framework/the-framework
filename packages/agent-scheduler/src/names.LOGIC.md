The names the tool hangs off, and its defaults. The tool's own directory is `.agent-scheduler` at the repository root, hidden from git by the tool itself; in it, the state [2] is `state.json` and `scheduler.log` is the scheduler's process's own log (a spawned run's lock and stderr are `agent-runner`'s, under `.agent-runner/`). The coding agent every scheduled run is on, Claude Code, reads a project's skills from `.claude/skills`: a skill that is only in another folder is no command to it. A skill's file is `SKILL.md` in the skill's folder: its front matter is where the skill says what it adds to the schedule [1]. The defaults: a scheduled run starts on `opus` when the state names no model; a run of a command [3] publishes at the level `commit`, so it commits its work and pushes nothing, on a machine where nobody picked a level for that command; the spend cushion is 100/14 percentage points, half a day of the week's allowance, the cushion OpenAgent's daemon used; a command for which neither its skill nor a person names a number runs 1 at a time, its cap [4]; a number of agents at once, a skill's or a person's, is a whole number from 1 to 99, and anything else is no such number (0, a fraction, 100, text): the one rule the state, the skill reader, the command line and the dashboard part all read; a started scheduler ticks every 60 seconds; a run that a command's check started is handed at most 8000 characters of what the check printed; a command's check may run 60 seconds before it counts as failed.

## Glossary

[1] the schedule: all the scheduled commands of a project. A skill of the project brings its own with the `schedule` key in the front matter of its `SKILL.md`, called the skill's `schedule`.
[2] the state: `.agent-scheduler/state.json` at the repository root, per user, hidden from git through the repository's exclude file.
[3] command: a scheduled command, one command a skill schedules: the skill's folder name and at most one word the skill takes as its argument, which the coding agent's harness expands from the slash command `/<name>`.
[4] cap: how many runs of one scheduled command a machine lets be in flight at once: the machine starts another run of the command only while fewer than its number are in flight on any machine that shares the repository. Its number is the agents pick made on it, a person's own number for the command there, else the number the command's skill gives, 1 when the skill gives none.
