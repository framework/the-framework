The pull request a branch has, read back for the run record: the agent opens its own pull request with the `branches` skill, and the run's process asks `gh` for the newest pull request whose head is the run's branch, open or closed, and keeps its number and URL on the card. No pull request, a `gh` that is missing or not signed in, an answer that does not parse, or a call past sixty seconds all read as "none": the run is recorded without a pull request, never failed for it.
