What the tests cover, on a skill file's text, and on skill folders in a throwaway directory:

- **A skill's schedule** - a `schedule` with `when`, `waits-for` and `agents: 2` reads as the skill's command with its check, what the check waits for and a cap of 2; one with only `when` reads with a cap of 1; a skill with no `schedule`, and a file with no front matter, give no command and nothing unreadable.
- **An interval** - `every: 6h` alone, and `every: 30m` beside a check and `agents` with the keys in another order, each read as their command with the duration and the text as written; a check written as a block, holding quotes, a comma, a colon and a backslash, reads as written.
- **A word** - a list of two rows, `word: quick` and `word: consensual`, reads as two commands named by the skill and the word, in the order written; one row with a word reads as its command; a list where one row has no word reads as `triage` and `triage quick`; the prompt of `triage quick` is `/triage quick`; a run's prompt is counted under the scheduled command it names (`/triage quick` → `triage quick`, spaces around it ignored), else under its first word (`/triage`, `/work-queue now`, a plain sentence), and under its first word when no command is scheduled.
- **An unreadable schedule** - an unknown unit, `every: 0h`, an `every` with no unit, an unknown key, a row with only `waits-for`, an empty `when`, a `when` that is a list, a `waits-for` of two lines, `agents: 0`, `agents: many`, a `word` of two capitalised words, a `schedule` that is one word, and an empty list each give no command and name the skill with the reason; in a list, one bad row stands the whole skill down and the reason names the row (`row 2: unknown key evry`); two rows with one name give `two rows are named <name>`; front matter that is not YAML names the skill with `the front matter is not YAML`.
- **Which skills are read** - a directory with no skills folder schedules nothing; with skills under `.claude/skills` and `.agents/skills`, each skill is read once and the commands come in the skills' name order; a skill in both folders with two texts follows its `.claude/skills` copy; a skill folder linked from one folder into the other reads like a plain one; a skill with no `schedule` gives no command; a skill whose `schedule` cannot be read is named with its reason while the others still count; a folder with no `SKILL.md`, and a plain file in the skills folder, are passed over.
- **Due** - a non-empty JSON array or object, `true` and non-JSON text are due; `[]`, `{}`, `null`, `false`, `""`, no output and blank output are not.
- **The prompt** - a command's prompt is its slash command.
