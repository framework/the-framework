A test helper, not business logic: a throwaway project for the tests: one commit on `main`, a bare `origin`, the `agent-data` branch born on origin, and a tracked `.claude/skills/work-queue`; real git, because the run records, the checkouts and the reclaim rule are git. Removed with its origin after each test. Beside it, a reader of a run's recorded diary that fails a test when a line carries no time as an ISO 8601 timestamp, and hands back the lines with the time taken off, so a test compares what happened.
