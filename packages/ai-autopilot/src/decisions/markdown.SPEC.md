Turns the ledger into DECISIONS.md — a plain markdown file the user can read and edit by hand, one section per decision with its status, title, and reason — and parses it back.

## Rationales

- Parsing is forgiving — a section without a status counts as rejected, unknown metadata is ignored, a broken section is skipped — so one bad hand-edit never sinks the agent's whole memory.
