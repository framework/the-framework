The prompt collection: prompts keyed by the id the loop dispatches, with loaders for the bodies shipped with the package and for a project's own folder.

## TLDR

- Look one up by id, list them all, group them by the change kind they target, or add and replace one — a project can swap in its own wording for any check.
- Loading the shipped bodies is one call, which is what makes the default loop policy work out of the box.
