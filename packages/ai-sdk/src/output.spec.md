Structured-output wrappers: `Output.object({schema})`, `Output.array({element})`, `Output.choice({options})` — each returns an `OutputWrapper` with a `parse(text)` (markdown-fence-stripping JSON extraction + zod validation; choice trims and enum-parses) and a `toSystemPrompt()` that embeds the JSON Schema (via `zodToJsonSchema`) with "output ONLY valid JSON" instructions. Parse failures throw with the original error as `cause`.
