The engine's source, mapped by area. Files with their own `<name>.spec.md`: `agent.ts`, `tool-execution.ts`, `scoped-tool.ts`, `resume-approval.ts`. Subdirectories with specs: `providers/`, `eval/`, `computer-use/`, `react/`, `budget/`, `gateway/`.

## TLDR

- **Core loop** — `agent.ts` (see spec), `types.ts` (every shared contract; the design notes live in its comments), `middleware.ts` (eight pure dispatch helpers fixing each hook's combination rule: config hooks are piped; chunk hooks are piped with drop-on-null; before-tool-call is first-answer-wins; the rest are side-effect-only), `handoffs-driver.ts` (the iterative handoff loop; capped hops against agent cycles; strips the leading system message so the child's own instructions aren't double-prefixed), `observers.ts` (process-wide event pub/sub on a `globalThis` singleton), `facade.ts` (the `AI` static facade).
- **Tools** — `tool.ts` (builders are themselves valid tools, no `.build()` step; the two pause control chunks are detected *structurally* so a tool author can construct them without importing the SDK; the generator overload must be declared first or TypeScript leaks the generator type), `tool-helpers.ts`, `handoff.ts` (a pseudo-tool with no execute, tagged via `Symbol.for` so identity survives a double-loaded SDK), `provider-tools.ts` (web search/fetch/code-execution builders that become provider-native blocks via `providerHint`, with fetch-based fallbacks), `zod-to-json-schema.ts` (Zod 4's native converter; strips the dialect key; falls back to a plain object shape so a tool always advertises something).
- **Output & wire formats** — `output.ts` (`Output.object/array/choice`: schema + parse + a system-prompt hint the loop itself never reads — and **no retry on mismatch**), `agent-sse.ts` (the package's own named-event SSE protocol, server framer and browser reader in one file so the vocabulary cannot drift; errors are events and the stream closes cleanly), `vercel-protocol.ts` (the Vercel v4 data-stream projection; pause/handoff/tool-update chunks have no v4 equivalent and are dropped — the stated reason the richer SSE protocol exists), attachment/file/image/audio builders, `chat-mentions.ts`.
- **Conversation & memory** — `conversation-persistence.ts` (spec precedence, thread selection, and ownership enforcement: permissive when a backend's listing is partial, refusing only when the listing is demonstrably not enumerating — with an error that never names the owner), `conversation.ts`, `memory.ts` (token-overlap recall — deliberately not embeddings), `memory-inject.ts` (prepends a tagged user-memory block under a token budget; runs in `onStart` because config hooks are synchronous), `memory-extract.ts` (distills durable facts with a small model on finish, so failed runs never pollute memory; every failure path is swallowed), `sanitize-conversation.ts`, `continuation-validation.ts`. Both auto-installed memory middlewares skip continuation calls — re-running them would duplicate blocks and double-write facts.
- **Run stores** — `agent-run-store.ts` / `sub-agent-run-store.ts` / `run-store-base.ts` (shared bodies, deliberately unexported): pause snapshots with `load` (non-destructive peek for a "waiting for approval" view) split from `consume` (atomic read+delete, so a forged or replayed resume id cannot read twice); short default TTL; ids from `crypto.randomUUID` because run ids are capability handles.
- **Retrieval** — `file-search.ts` (provider-native hosted RAG on OpenAI/Google; on other providers it degrades to a plain function tool, and without the local-search fallback installed it would pause as a client tool — the fallback closes the cascade), `similarity-search.ts` (vector search over an ORM model's column, typed structurally so the package has zero ORM dependency), `rerank.ts`, `cached-embedding.ts`, `vector-stores/`.
- **Queue** — `queue-job.ts` (fluent queued prompts; dispatch/broadcast are module-level configured loaders; broadcast failures are swallowed so they can't mask the original error).
- **Registry** — `registry.ts` (static over a `globalThis` store — the double-load fix; model strings split on the **first** slash so `openrouter/vendor/model` works; adapters are recreated per call, only the lazy SDK client behind them is memoized; a reset notifies listeners so sibling caches clear in lock-step).
- **Testing** — `fake.ts` (see package spec).

## Facts

- `await response` on a stream resolves only after the stream is fully consumed; a rejection wrapper rejects that promise before re-throwing into the iteration, without which a mid-stream abort would hang the awaiter forever.
- A caller abort short-circuits failover — an abort never burns the fallback list.
- The streaming parallel-tool-call fix: providers interleave concurrent tool-call deltas by index (and some send no index), so partials are tracked in two maps sharing references, with index-routed deltas falling back to the most recent partial. Without it, a second tool call's fragments silently landed on the first.
