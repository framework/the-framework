Fluent speech-to-text facade — `Transcription.fromBytes(bytes).model('openai/whisper-1').language('en').prompt(...).failover(...).generate()` resolves the provider's `createStt` adapter via `AiRegistry` (throwing when the factory lacks it) and runs through `tryWithFailover`. `fromBuffer` is a deprecated alias of `fromBytes`; Node path-based loading lives in `@gemstack/ai-sdk/node` (`transcribeFromPath`).
