Tiny helpers shared across the AI SDK: flattening mixed message content down to plain text, fingerprinting text stably for prompt-cache keys, and pausing between rounds of a polling loop. Everything here runs in any JavaScript runtime — no server-only dependencies — so the package's main entry stays usable everywhere.
