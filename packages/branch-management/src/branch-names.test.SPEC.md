Covers the naming rules: the session name is read off a branch — `tf-<session name>` gives the name, suffixed or not, while the birth spelling `tf-agent-<agent id>`, the data branch, a user's own branch and no branch at all give none — and the birth spelling is both a framework-minted branch and a checkout directory name, where a named branch is only the former.
