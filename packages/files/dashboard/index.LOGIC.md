What the Files module adds to the dashboard, as its `./dashboard` export declares it: two side-rail tabs and an agent's page's two run slots. The first tab is labeled "Changes", with the tooltip "Only the files that changed: a session’s, kept after its work is merged, or the project folder’s own — the list on the left, the picked file’s diff on the right.", with no count, and drawn by the list (`ChangesPanel.tsx`); being first, it is the tab the side rail rests on. The second is labeled "Files", with the tooltip "The project’s files, or a session’s with what it changed marked while that is not merged yet — hover one to preview it, click one to add it to the next run’s Context.", counting on its label the Context's [1] files, and drawn by the tree (`FileTree.tsx`). The two run slots [2] are the count of changed files as the summary and their list as the details (`AgentChanges.tsx`). Its stylesheet is linked with it.

## Glossary

[1] Context: the set of paths the user picked to focus an agent on: other registered projects, by their absolute path, and files of the current project, by their path relative to the repository's root.
[2] run slot: a place on an agent's page a module fills: the summary, a few words in the bar above the message box, shown while that bar is drawn and until the agent has ended and its branch has been read (the handoff's own words take over then); and the details, a block under the action bar at the top of the page. Each is told the agent, whether it is still working, and whether the action bar is open.
