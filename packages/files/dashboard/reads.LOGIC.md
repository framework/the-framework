The Files module's five server reads (`../src/server.ts`) as its components call them: the project's files, an agent's tree, a file's diff, a file's contents, and a working agent's changes, each for one project, an agent's read carrying the agent's id. Each asks through the dashboard, and a read that answers an error is turned into a failure, so a component that polls keeps the last answer it showed instead of an empty tree.
