The Files module's seven server reads (`../src/server.ts`) as its components call them: the project's files, an agent's tree, a file's diff (an agent's may name one commit of the agent's work, and is then that commit's alone), a file's contents, a working agent's changes, an agent's commits, and what one of those commits changed, each for one project, an agent's read carrying the agent's id. Each asks through the dashboard, and a read that answers an error is turned into a failure, so a component that polls keeps the last answer it showed instead of an empty tree.
