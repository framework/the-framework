What the tests cover:

- **A tracked file's diff** - a modified file yields its hunks without git's `diff --git` and index preamble, with added and removed lines counted and the file headers not counted; a removed line that looks like a file header (`----`, `--- a note`) is still counted; a file with no diff yields nothing rather than an empty card; a binary change is flagged binary with an empty body; a patch over 500 lines is cut to 500 and flagged as cut; a repository with no commits falls back to the working-tree diff.
- **An untracked file** - rendered as all-added from its contents without git ever being asked; a long untracked file is counted whole while its preview is cut at 500 lines; an untracked file reached through a symlink that points out of the repository is refused.
- **Path safety** - plain repository-relative paths pass; an empty path, traversal (`../`, `src/../../`), an absolute path, a Windows drive path, a leading dash, `.git` in any casing or position, a double slash and a NUL byte are all rejected; an unsafe path is refused before any read and git never runs.
- **The "Changes" list** - every changed file is counted from one numstat read (one git call, not a diff per file), a `-` count marks a binary file, a deleted file carries its removed count; an untracked file, which no diff lists, is counted from disk; the list is sorted by path; an unsafe path is dropped rather than passed to git; a clean checkout yields an empty list without asking git.
