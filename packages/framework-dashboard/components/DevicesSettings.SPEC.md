The settings section for the saved devices — other machines running The Framework that a session can run on — listed with live online/offline badges, plus add and remove.

## TLDR

- Unlike everything else in settings these are not preferences: a device carries its own access token, so the roster lives in this browser only and does not follow you to the next one — and the section says so.
- Removing the device currently chosen as the run target also clears that choice, so the next run cannot point at a machine no longer on the list.
