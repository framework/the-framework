The launcher's questions hub: every session's open question across all projects, answerable in one place, longest-waiting first.

## TLDR

- Each card names the session asking and offers the way into it; an answer posts against that session's own run.
- An answered card collapses in place to a ✓ line that re-expands to show what was picked — it never vanishes under the cursor — and the memory is per-visit, so a reload starts clean.
- The Autopilot countdown never runs here: a page that shows every parked gate at once must not auto-accept them all.
- With several questions a stationary jump-nav maps them; with none, the section does not render at all.
