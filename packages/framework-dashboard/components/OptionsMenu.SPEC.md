The options gear: the run options as one checkbox dropdown that writes each preference straight through, topped by the single-choice "Run on" picker for where the run executes.

## TLDR

- "Run on" is one flat list with exactly one checkmark: this machine, a fresh GitHub Actions runner, a hand-off to a Claude web cloud session, then the saved devices — each with a reachability dot and removable in place — and "Add a device".
- Picking a device makes it the run target where you are, no navigation; "This machine" while browsing a remote daemon means "go home" instead.
- A disabled option stays visible with the reason it does not apply and cannot be flipped; Eco's sub-options appear indented only while Eco applies.
- The trigger wears a small dot whenever any option is on.
