One session's view, live or finished, in a stable frame — action bar, details, changes/handoff, transcript and composer — whose contents change instead of the page remounting when the run ends.

## TLDR

- The transcript is one log with two sources: the live channel while the run works, the archived copy once it ends — swapped in behind the events already on screen, so a session ending (the moment you are most likely reading it) never blanks the page.
- An empty archive never replaces events on screen; a stale archive never hides a resumed session's new leg; a foreign journal never beats the run's own record; and the archive is re-read once the feed outgrows it, which is how the epilogue's push/PR events arrive without a manual refresh.
- "The agent is done" means it settled, not that the process died: a parked session stays alive for your next message, so the handoff summary, arming checkbox and actions key off settling.
- While the agent works the bar summarizes its worktree's changes; after settle it swaps — once loaded, never via a blank beat — to what the branch holds.
- Runs executing elsewhere say where the work really is: an Actions run explains its burst-at-the-end replay, a web run points at its cloud session, a device-relayed run notes only the preview stays local.
