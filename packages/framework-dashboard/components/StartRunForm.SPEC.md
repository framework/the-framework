The launcher form that starts a session in the selected project: the shared composer plus the actual submit, the Context selector, and the system-prompt preview.

## TLDR

- A typed prompt starts an attended conversation; a preset starts unattended routine work that ends at settle with its armed handoff firing.
- The options sent and the prompt previewed come from the same mapping the run itself uses, so the form cannot disagree with the session it starts; a picked device adds relay to that device, and its secret token rides in memory only.
- Preflight warnings spend words before the session is spent, and never block: a project Claude has not been trusted in (doomed web run), an agent CLI that cannot start at all — with the GitHub CLI checked only when a PR or merge is armed — a repo whose disabled auto-merge turns an armed merge into an immediate one, and Haiku's known failure to finish properly.
- A start is answered immediately: an optimistic rail row appears and the view jumps to the run before its record even exists.
