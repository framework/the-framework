How many errors an agent [1] reported, said in red where the feed cannot scroll it away: the agent view's action bar and the project home's summary block. The errors themselves stay in the feed at the point where the agent hit them; this is the count, "1 error" or "<N> errors", with a warning icon, and nothing at all when the agent reported none. Where the row has room for it, the latest error's headline follows the count after a middle dot, truncated; in a tight bar the count stands alone, since a count clipped to "1 erro" is worse than none, and the count never gives up width. Hovering the count lists every error's headline, one per line, so an agent with several says which; the detail of each error stays in the feed.

## Glossary

[1] agent: the unit of work: one task worked by a coding agent under The Framework's control — in its own checkout, on its own branch, streaming events, handed off when it ends.
