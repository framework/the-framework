What the tests cover, for the dashboard's left column and its list of agents:

- **A working agent** - reads "running" with a pulsing dot.
- **A waiting agent** - an agent that ended on its question reads "waiting", never "running", with a still dot and nothing pulsing.
- **Saving** - a done agent the daemon marks saving reads "saving…" with a pulsing dot and never "done"; a done agent without the mark reads plain "done".
- **The starting row is highlighted** - when the page selects an agent whose row has not landed yet, the stand-in row carries the highlight and the "New agent" button does not.
- **The starting row reads as the real one will** - with every project showing it reads "running", the project and "just now", then the prompt; with one project picked, "running", "just now", the prompt; never "starting…", and it is not dimmed.
- **The starting row retires on landing** - the stand-in goes as soon as the agent with the id the start reported appears, even one that landed already "failed" without ever being seen running; another agent already listed does not retire it; an agent the list already holds when its start reports it gets no stand-in, while it runs or after it ends.
- **Where an agent runs** - a relayed agent shows a device glyph named "Runs on <device>"; an agent another machine's daemon started shows a glyph named "Started on <host>", while this daemon's own agents show none; a local agent shows no device glyph.
- **The column with no project picked** - with no project and no agents it still shows "New agent" and "No agents yet."; with pooled recent agents each row names its project, and selecting one jumps into that project and that agent.
- **"New agent"** - with one project it starts in that project; with a project picked it starts in that project; with several projects and none picked it opens a picker instead of starting, on a project's own page too.
- **Cloud sessions** - a finished web agent reads "in cloud", not "done"; a stopped web agent reads "stopped"; a web agent whose cloud session the bridge reports as parked reads "waiting"; a web agent with a pull request reads "done", one whose adopted work merged reads "merged", and an old one with nothing adopted reads "done"; a web agent shows the cloud glyph and still names "Claude Code" as its coding agent; a local finished agent reads "done" with no cloud glyph.
- **Long titles** - a title that overflows the column shows the full prompt in a tooltip on hover; a title that fits has no tooltip.
- **The project select** - the button names the picked project, or "All projects" when none is picked; choosing a project, or "All projects", reports the pick, and a tick marks the current one; a project the daemon recorded an error for gets a red dot and the error in words ("Not syncing with the remote"), with the daemon's message on hover, and a project that is not activated reads "Not activated"; an activated project whose repository has no remote reads "Local only, no remote" in grey, with no red dot, and one whose repository has a remote the person keeps the agents' records from reads "Records kept on this machine" in grey; with no project picked, the row of the agent whose page is open is the highlighted one.
- **Subagents under their main agent** - while a subagent works, the list under its main agent is open, the count named "2 agents · 1 running", each subagent named by its task without the lines every subagent is told, oldest first whatever the list's order; a subagent waiting on a question keeps it open too; once every subagent has ended it folds to "2 agents", and a click opens it and a second folds it again; the user folding the list of a working subagent wins; the list of ended subagents is open while one of them is the selected agent, and a click on a subagent selects it; a subagent whose main agent is not in the list is a plain row, and an agent with no subagents has no fold line; on the Overview a subagent sits under the main agent of its own project, not under an agent with the same id in another, and its row does not name the project again.
- **A main agent whose subagents still work** - a main agent that is done, and even marked saving, reads "running" with one pulsing dot, never "done" or "saving…", while a subagent is running, and "done" once none is; a main agent that failed keeps "failed" while a subagent is running.
- **The moment after a subagent ended** - a main agent that is done reads "running" while its subagent ended a few seconds ago, and no longer once that end is older.
- **The count on the main agent's row** - the count of subagents is inside the main agent's own row, and a click on it folds and opens the list without selecting the agent.
- **Reading an ended agent ahead** - the pointer reaching a done agent's row reads its archive before any click, and reaching it a second time reads nothing more; the keyboard focus reaching a failed agent's row reads it too; a running agent's row reads nothing; with no project picked, a row of the pooled list reads the archive in its own project.
