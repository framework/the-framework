What the tests cover:

- **What an entry reads as and opens** - a queued ticket's row shows the link's title with the whole raw line as its tooltip, and clicking it opens that ticket's page in the ticket's own project; an entry linking to a web address is a real link opened in a new tab; a plain entry is plain text and nothing on the row but the play button, the fan-out button and their two chevrons is a button.
- **The play button** - starts, in the clicked entry's project, a prompt agent whose prompt carries that entry's raw line (not the first entry's) and which runs unattended, then hands the started agent over for navigation; when the daemon names no agent yet, the project is handed over without an id so the running agent can be adopted; the button's tooltip reads "Spin up an agent working on this entry".
- **A failed start** - a refusal navigates nowhere and its message, "already active", stays on screen as an alert.
- **Disabled while starting** - with a start in flight every play button and the fan-out button are disabled, while the "Other ways…" chevrons stay enabled because they start nothing.
- **The fan-out** - by default starts three unattended prompt agents, one per top open entry in queue order and skipping done entries, in the entry's project, without navigating; the count box sets how many; the button's promise is capped at the open entries (two on a two-entry queue) and reads singular for one ("Spin up an agent working on the top entry"); the batch stops at the first refused start; every start button stays disabled for the whole batch, including the gap between two of its starts, and comes back once it ends.
- **"Configure first, then run"** - an entry's chevron opens its own project's launcher with that entry's prompt stashed as a draft and starts nothing; the fan-out's chevron says "one agent, not the batch" and stashes the top entry's prompt alone; a chevron in a second project's row lands on that project, not the first.
- **What is listed** - done entries and projects with nothing open are not shown; the card reads "Loading…" while loading and "Nothing queued." when empty.
