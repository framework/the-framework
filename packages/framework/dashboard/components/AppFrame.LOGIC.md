The dashboard's outer shell: it applies the user's color theme, "system" (follow the operating system, the default until the preferences arrive from the daemon, so a dark-OS user gets a dark first paint), "light" or "dark", to the whole page, following live changes of the operating system's scheme only while the choice is "system"; and it wraps everything dynamic, the live feed, the polled panels, the markdown, in the error boundary (`ErrorBoundary.tsx`), so a crash shows its recoverable card on the app's own themed background rather than the browser's blank white. How the theme preference resolves is in `lib/preferences.ts`.
