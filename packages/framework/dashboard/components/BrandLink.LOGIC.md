The logo mark and the "The Framework" wordmark in the header, which are the way home: a real link to `/`, the Overview. A plain left click navigates within the app through the shell's own router, the same way every other selection does; a click with Cmd, Ctrl, Shift or Alt held, or with the middle button, is left to the browser, so it can open a second Overview in a new tab or window, and "copy link address" yields a URL. Below the small breakpoint the wordmark folds away so the header fits a narrow viewport, and the mark alone stays the link home. The mark animates while an agent is working, as `Logo.tsx` draws it.
