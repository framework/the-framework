What the tests cover:

- **The notice row** - before the hand-off names a session the row says "Starting a Claude Code cloud session" and offers no link; once the driver reports the session, "Open the session" links to its URL, the row shows `claude --teleport <session id>`, says the session opens its own pull request, and says a question it parks on shows here; nothing at all is rendered for a `local`, `actions` or `remote` location, or for an agent with no location.
- **The parked question** - once the bridge reports a question, its title, its options as buttons and the "Recommended" mark appear inside the same "Your call" gate card a local agent gets; the question is asked for by the cloud session's id; "Answer it in the session" links out to the session; with no parked question nothing extra is shown; before the hand-off lands the daemon is never asked.
- **Answering from the dashboard** - one click on an option queues that label through the bridge, never through the agent's control file; a multi-select queues the checked labels, defaults included; a refusal from the daemon shows its reason on the card; a queued answer reads "Sending “Cross-project only”" with the question card gone so a second pick cannot race the first, and "Cancel" withdraws it; a typed answer reads "Answered “Cross-project only”" with no "Cancel"; a failed delivery shows "failed: <note>" and offers the question again.
- **The mirror at the log tail** - the session's turns are shown in order inside one box named "Cloud session mirror"; a user turn is one line prefixed "you ›" with its first line only and the whole turn as the tooltip, while the session's turns are shown whole; "Connecting to the cloud session" shows before anything arrives; claude.ai interface lines ("Arrow keys move the tile…", "Show message actions", a bare model name) are dropped; nothing is rendered, and the daemon is not asked, before the hand-off or for another location; the notice row itself no longer carries the transcript.
- **Scrubbing mirrored text** - the scrub is anchored per line, so a sentence merely mentioning a model or arrow keys is kept; the holes dropped lines leave are collapsed; a turn made only of interface lines scrubs to nothing.
