The header's "connected to" indicator: which daemon the dashboard is talking to. Every request the page makes goes to the origin it was served from, so the origin is the connection: a loopback address is this machine's own daemon, shown as "Local" in muted style (and only from the small breakpoint up), with the tooltip "Connected to this machine"; any other origin is a device [1] the user hopped to, shown by its saved label, or by the bare host when it is not saved, drawn accented so a remote box, where the agent runs on someone else's hardware, is never mistaken for one's own, with the tooltip "Connected to <label> — the agent runs on that device". A dot beside the icon is green when the connection is online: always on "Local", and on a device only once the reachability check has reported it online (grey while unknown or offline; the check is in `lib/use-device-status.ts`). When the page boots, the indicator also remembers the loopback origin it was launched from, so "This machine" can lead back to the right port from a remote box, and moves a draft carried in the URL into the page's holding place before the prompt reaches the address bar (`lib/draft-handoff.ts`).

## Glossary

[1] device: another machine's daemon the user saved by URL and token, to run agents on it from this dashboard.
