The list of files picked into the launcher's "Context", the set of files and projects an agent is told to focus on: one row per file with its repository-relative path and a remove cross named "Remove <path> from context" (tooltip "Remove <path>"), disabled while the launcher is busy. A file reaches the Context either through a `#` mention in the prompt or through the right rail's file tree, and both add the same path; this list is what keeps a picked file visible once the prompt is cleared, and removing a file here also unticks it in the file tree. With no files picked the list is absent.
