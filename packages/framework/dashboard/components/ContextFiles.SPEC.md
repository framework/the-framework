Lists the individual files the user has picked into an agent's Context, each with a remove button, so the picks stay visible after the prompt is cleared.

Files enter the Context two ways — a `#` mention typed in the prompt, and ticking a file in the right-rail file tree — and both land in the same set, listed here by their path relative to the repo. Removing a file here also unticks it in the file tree. Whole repos in the Context are listed elsewhere; this list shows only files. While the Context is being changed, removal is disabled.

## Glossary

- **Context** - the repos and files the user hands an agent to start from.
