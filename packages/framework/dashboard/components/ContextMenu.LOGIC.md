The launcher's "Context" picker, a dropdown on the composer's control row through which the user narrows an agent's [1] focus to other registered projects and to specific files. Its trigger reads "Context", followed by " · " and the launcher's summary of what is picked ("2 projects · 1 file") when anything is; its tooltip says "Narrow the run to specific repos and files"; it is disabled while the launcher is busy. The menu has two groups. "Projects" lists every registered project other than the current one as a checkbox by name, with the project's path as its tooltip, and the group's own tooltip states the rule: "The agent can still reach every repo; ticking some just narrows its focus."; with no other project registered it says "No other repos to add.". "Files" lists the files picked through a `#` mention in the prompt or through the right rail's file tree, each with a remove cross (the list in `ContextFiles.tsx`), or says "None yet — add with # or the Files tab." when there are none. Ticking or unticking a project and removing a file both change the same Context set the launcher keeps.

## Glossary

[1] agent: the unit of work: one task worked by a coding agent under The Framework's control — in its own checkout, on its own branch, streaming events, handed off when it ends.
