The shared open/close control for the dashboard's collapsible sections: a chevron that turns when the section is open, followed by the section's label, muted until pointed at.

Used by every disclosure under the agent controls (for example "See actual prompt sent") so they all read the same, and announces its open or closed state to assistive technology.
