What the tests cover: the trigger shows the current driver's logo and the current model, and names the driver in words when pointed at, since the logo alone names nothing; picking a model inside a driver's submenu sets that driver and that model together; each driver's submenu lists only its own models, never the other driver's; with no model pinned, and with a model that belongs to the other driver, the trigger names no model and reports "the CLI's own default" rather than claiming whichever model happens to be listed first; and the trigger carries a spoken name covering both driver and model even when it shows nothing but a logo.
