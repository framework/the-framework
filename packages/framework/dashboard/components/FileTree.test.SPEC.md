What the tests cover: with no agent selected the tree reads the project's own checkout, and with one selected it reads that agent's worktree — so the marks agree with the branch and actions shown above the tree instead of showing a clean project next to another checkout's changes; switching to a different agent re-reads rather than keeping the previous one's marks; and a file the agent changed carries the letter for that change.
