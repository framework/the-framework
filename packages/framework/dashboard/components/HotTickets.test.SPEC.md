What the tests cover: tickets are grouped into the three lanes (In progress, AI Queue, High priority); with nothing hot the card names those lanes instead of claiming no tickets exist; a ticket an agent is implementing is tagged "implementing" — which outranks the "planned" mark left by earlier work, and is shown even for a ticket that carries no plan at all.

Row selection: a ticket that names an agent opens that agent rather than its project home; a ticket with no agent opens its project instead, and the click carries a composer draft naming that ticket's file (not its title) so the launcher arrives pre-asked to work it. A click that opens an agent leaves no draft behind, so nothing leaks into an unrelated launcher visited later.
