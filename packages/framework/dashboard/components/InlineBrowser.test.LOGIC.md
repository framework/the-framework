What the tests cover, for the browser preview inline in the transcript:

- **Live** - while the agent [1] is live the row hosts the interactive browser pane inside the box.
- **Ending under the reader** - when the agent ends while the pane is on screen, the pane gives way to the last still ("The browser's last frame") captioned "preview ended — session finished", and the live pane is gone.
- **Ended with nothing captured** - a row whose agent is not live and that captured no still is just the one-liner "browser · <url>", with no image, no dead stream and no spinner.

## Glossary

[1] agent: the unit of work: one task worked by a coding agent under The Framework's control — in its own checkout, on its own branch, streaming events, handed off when it ends.
