What the tests cover: the three rungs of the inline browser preview's degrade ladder — a live agent shows the interactive preview in its box; an agent that finishes while the user is watching leaves the last frame it saw on screen with the "preview ended — session finished" overlay and no live view; and an agent already finished with no frame ever captured shows only the one-line note naming the page, never a dead stream or a spinner.
