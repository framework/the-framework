The page shown when a URL no longer resolves — a bookmarked or pasted agent [1] link whose checkout [2] has been removed, or a project dropped from the registry: a centered title, a one-line detail, and one outlined button offering the way back, all three worded by the surface that shows it. It never redirects silently, because a redirect looks like the link worked and the user clicked the wrong one.

## Glossary

[1] agent: the unit of work: one task worked by a coding agent under The Framework's control — in its own checkout, on its own branch, streaming events, handed off when it ends.
[2] checkout: an agent's own working copy of the project: a git worktree under the project's `.branches/` directory, named as its branch.
