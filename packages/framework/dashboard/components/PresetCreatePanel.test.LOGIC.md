What the tests cover:

- **Prefilled and saved** - the prompt box opens with the editor's current text; typing a name and clicking "Save preset" hands over a preset with that name, that prompt and a fresh id; with no project open it is saved as the user's own.
- **Both fields required** - "Save preset" is disabled while the name or the prompt is empty.
- **Saving to the project** - with a project open, choosing "This project" and saving reports the project as the destination.
- **No destination choice without a project** - the "This project" option is absent when there is no project to share into.
- **Cancel** - "Cancel" backs out once.
