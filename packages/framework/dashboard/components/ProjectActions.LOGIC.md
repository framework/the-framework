The action bar at the top of the project home [1]: the project's git status on the left (`GitStatusBar.tsx`) and the workspace actions on the right (`WorkspaceActions.tsx`). Both halves are the same ones an agent's [2] page shows; here they are given no agent, so they report on and act on the project's own checkout rather than an agent's.

## Glossary

[1] project home: a project's own page with the launcher (the Start form) and its composer (the prompt editor, also used for live chat).
[2] agent: the unit of work: one task worked by a coding agent under The Framework's control — in its own checkout, on its own branch, streaming events, handed off when it ends.
