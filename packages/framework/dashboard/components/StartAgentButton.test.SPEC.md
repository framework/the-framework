What the tests cover: the start button's two halves.

**The press runs it.** Clicking the primary half starts the work and opens no launcher, and carries no prompt anywhere — a click that runs it now has no launcher trip to prepare for.

**Configure first, then run.** Taking the menu entry opens the launcher and starts nothing, carrying the button's prompt verbatim so the launcher opens on it rather than on an empty composer.

**What closes which half.** A start in flight closes the primary half and leaves the chevron open and usable, since it starts nothing. Having nothing to act on closes both halves. Only the button whose own start is in flight shows the busy wording.

**The menu entry.** It carries the caller's own description of what the launcher trip is for, including "one agent, not the fan-out" where the press would start several.

**Naming.** An icon-only button and its chevron each keep an accessible name of their own, and the hover still says what the press costs when there is no label.
