The frame both ticket pages sit in — a ticket's own page and its plan's page: a "Tickets" button with a back arrow that returns to the list, optionally the repository-relative path of the file the page renders beside it, and below that the page's content in one scrolling column of a fixed reading width. Both pages get the same way out and the same measure, so neither reads as a different kind of page than the other. It also fixes how those pages phrase a wait or an absence: one muted line of text, used for "Loading…", "This ticket does not exist." and "This ticket has no plan yet.". The path is shown only where the page's own heading does not already name the file.
