What the tests cover: on an agent, the folder and editor actions open that agent's own worktree rather than the project's tree; on a project, they open the project's checkout; and both surfaces offer the same set of actions, so an agent is never missing the repo link, the folder or the editor.

The editor picker: choosing a detected editor stores it as the preferred editor, choosing Default clears the preference, and an editor the user set by hand that the machine does not detect still appears as a selectable option.
