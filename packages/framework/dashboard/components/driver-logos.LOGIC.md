The two brand logomarks the dashboard shows for the coding agents [1] it drives: Claude's starburst and Codex's mark, drawn in the surrounding text's color at whatever size the caller asks for, so a driver [2] can be shown as a logo rather than spelled out — in the driver picker and beside an agent [3] in the lists. A caller that has the user's driver choice gets the matching mark without repeating the mapping: `codex` shows Codex's mark, anything else Claude's. The mark is decorative wherever a visible label already names the driver, and carries the driver's name for assistive technology only where it is the only thing naming it.

## Glossary

[1] coding agent: the CLI doing the actual work: Claude Code or Codex.
[2] driver: a coding agent wrapped as a black box: start it in a directory, prompt it for one turn, stream what it does, resume it later. The user's driver choice is `claude` or `codex`.
[3] agent: the unit of work: one task worked by a coding agent under The Framework's control.
