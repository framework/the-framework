Turns the plain token strings in the composer's prompt editor into chips: every `<MACRO>` tag or `show…()` call found in the editor's text, recognized and normalized by the rules in `tokens.ts`, is replaced by its chip, all at once, which is how a just-loaded preset shows its tags as pills. Text inside an inline code span is left untouched, so a span such as `path/<SESSION_NAME>.md` stays one verbatim code span instead of being split around a chip. With nothing to convert, the editor is left exactly as it is.
