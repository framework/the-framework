Turns the macro tags and agent actions written as plain text in the prompt editor — typically the ones a just-loaded preset brings in — into chips, so a loaded preset looks exactly like a prompt the user assembled from the menus. Text inside an inline code span is left alone, so something like `path/<SESSION_NAME>.md` stays one verbatim code span instead of being broken around a chip.

## Before modifying/creating SPEC.md files

You must always read and respect https://raw.githubusercontent.com/brillout/sdd/refs/heads/main/sdd.md
