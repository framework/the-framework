The dashboard's checkbox: an empty box that fills with the accent color and shows a checkmark when ticked, dimmed and unclickable when disabled. It is drawn by the dashboard rather than by the browser, so it follows the dashboard's theme and shares the same keyboard focus ring as every other control.
