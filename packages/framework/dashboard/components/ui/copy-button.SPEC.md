A small copy-to-clipboard icon next to the strings the user takes to a terminal or a browser — agent branch names, session ids, URLs. Its tooltip names what will be copied; on a successful copy the icon turns into a green checkmark reading "Copied" for about a second and a half, so the user sees the click land, then reverts.
