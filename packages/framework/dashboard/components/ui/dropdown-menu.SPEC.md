The dashboard's dropdown menu — a panel of choosable entries opened from a button, with grouped and labelled sections, separators, submenus that open sideways behind a chevron, and tickable entries that show a checkmark. Picking a plain entry closes the menu, but ticking a tickable entry leaves it open so several options can be flipped in one pass. The button that opened the menu stays visibly lit for as long as the menu is open, and a menu too long for the space left on screen scrolls inside itself using the dashboard's own thin overlay scrollbar.
