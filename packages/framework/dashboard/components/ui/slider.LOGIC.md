Provides the two-thumb range slider the tickets filter uses for its fine-grained ranges: the user picks a lower and an upper bound, both inclusive, in whole-number steps between a minimum and a maximum that default to 0 and 10, and the host is told the pair whenever either thumb moves. The two thumbs are announced as the host's label followed by "minimum" and "maximum", or as "Minimum" and "Maximum" when the host gives no label.
