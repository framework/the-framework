Decides what an agent is called wherever the dashboard lists agents.

The label is the first of these that exists: the task the user typed, the agent's own session name, the agent branch its work landed on, then — when nothing describes the agent at all — the short date and time it started. Agents started from a preset or resumed from the CLI carry no typed task, so the fallback ladder guarantees every row still carries an identifying name rather than an empty placeholder.
