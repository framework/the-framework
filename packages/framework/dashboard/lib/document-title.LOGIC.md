Names the browser tab after what is happening, so a dashboard left open in a background tab says by itself whether it wants attention and which project is on screen. The title is the number of interventions [1] waiting across every project in parentheses, then the selected project's name and an em dash, then "The Framework" — for example "(2) gemstack — The Framework". With nothing waiting, the count and its parentheses are left out; with no project selected, the name and its dash are left out, leaving the plain "The Framework". The tab is renamed whenever either of the two changes.

## Glossary

[1] intervention: something that needs a human — an open question, a pull request to review, unpushed commits.
