Keeps the browser tab's title telling the user what the dashboard currently wants from them.

The title is the count of things needing the user, then the selected project, then the product name — for example `(2) gemstack — The Framework`. Each part drops out when it has nothing to say: no count while nothing needs the user, no project while none is selected. A static product name would hide which of several open tabs is the one asking for attention.
