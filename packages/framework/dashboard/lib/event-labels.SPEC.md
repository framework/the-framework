Names each line of an agent's event log in words a first-time viewer understands, for the badge shown beside it.

Only the event kinds whose own name is internal jargon are renamed: the driver's turn reads "agent", an agent waiting for the user's next message reads "waiting", the spend so far reads "cost", and the resumable session id and link read "resume". Every other kind keeps its own name with hyphens turned into spaces.
