Reports whether this browser will let the dashboard show notifications, as a value that stays current: allowed, blocked, not yet asked, or unsupported on a browser that cannot show notifications at all. Browser delivery is switched on in the user's preferences, but the browser's permission is the real gate, so the notifications menu and the Overview's onboarding checklist both ask this and both offer the user the step of granting it. The permission can change at any moment — the user can grant it from the dashboard's own prompt, or revoke it in the browser's site settings — and no browser reliably announces that, so the value is re-checked every three seconds and every place showing it updates together. A page rendered before the browser is running reads as unsupported until it is live.
