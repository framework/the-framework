What the tests cover: the shared answer to which notification channels the daemon can deliver on. Several places on screen asking at the same moment produce a single read of the daemon rather than one each. Re-reading after a credential is saved settles every one of those places on the new answer together, instead of leaving some still claiming "not configured". A failed read keeps the last known answer rather than blanking it to "not configured".
