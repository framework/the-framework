What the tests cover:

- **Reading a path** - `/` and an empty path select the Overview; one segment selects a project's home; two segments select one agent of that project; a trailing slash and any extra segments are ignored; segments are percent-decoded (`a%20b` reads as `a b`, `c%2Fd` as `c/d`) and a segment with a malformed escape is kept exactly as typed.
- **Reserved first segments** - `/settings` selects Settings and `/tickets` the cross-project tickets list, each also with a trailing slash or a stray segment after it; only the exact word is reserved, so `/settings-a1b2`, `/my-settings`, `/tickets-a1b2` and `/my-tickets` all select projects.
- **A project's tickets** - `/<project id>/tickets` selects the project's tickets page rather than an agent, with or without a trailing slash, while `/<project id>/tickets-ab` selects an agent; a third segment names one ticket by its filename and a stray segment after it is ignored; `plan` as the fourth segment past a ticket file turns on the plan view, while `plan` as the third segment is only a ticket file.
- **Writing a path** - the Overview, a project home and an agent view each write their path; an agent without a project writes `/`; segments are percent-encoded; Settings outranks a stale project id and agent id; the cross-project tickets list writes `/tickets`; a project's tickets page outranks a stale agent id; a ticket's page appends its filename, encoded; the plan view appends `/plan` past the ticket's path, and the plan flag is dropped when there is no ticket file.
- **Round trip** - every route shape reads back unchanged from the path written for it.
