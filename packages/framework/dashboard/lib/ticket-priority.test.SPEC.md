What the tests cover: a ticket's priority reads as its number on the 0-to-10 scale; a ticket that names no priority, or names something that is not a number, counts as having none rather than as a broken value; and the colour follows the same thresholds — danger from 8 up, warning from 5 to 7, muted below that and when there is no priority at all.
