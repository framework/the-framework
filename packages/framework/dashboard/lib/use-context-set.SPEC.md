The set of paths — files, directories, or the whole repo — that the user picked to focus a new agent on, which the dashboard shows as the agent's Context. The dashboard shell owns the one set, so the start form's `#` picker and the file tree beside it are always the same selection rather than two lists that can disagree; deleting a path's chip from the prompt likewise takes it out of the set. Selecting a different project clears the whole set, since the paths belonged to the project the user just left.
