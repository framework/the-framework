Mounts the dashboard into the `#root` element of `index.html`, and refuses to start without it. The app is wrapped in the frame that applies the user's theme and in the error boundary: the theme is "system", "light" or "dark", where "system" follows the operating system and is the choice until the preferences arrive, so a user on a dark system gets a dark first paint (`components/AppFrame.tsx`); a rendering crash becomes a "Something went wrong" card offering "Try again" and "Reload" on the dashboard's own background instead of a blank page, and never touches the daemon or the agents it runs (`components/ErrorBoundary.tsx`). The daemon serves one static page plus assets and answers calls; which page the dashboard shows is decided in the browser from the URL (`App.tsx`).
