The world the dashboard's component tests act in: a user who hovers a hint and reads the tooltip it opens, who opens a menu and waits until it is open, and who takes a start button's "Configure first, then run". Every hint in the dashboard is the custom tooltip, opened by hovering, so a test hovers like a user does and keeps hovering until the tooltip appears, for up to 5 seconds; moving off the hint closes it, so the next hover opens the only tooltip on screen. A menu is opened by clicking its trigger until the trigger reports itself open: a click can land before the menu is ready and do nothing, so it is repeated, but never on a menu that is already open, and a menu that will not open fails the test. "Configure first, then run" is taken by opening the chevron menu beside a start button and choosing that entry, the second half that every surface starting an agent shares.
