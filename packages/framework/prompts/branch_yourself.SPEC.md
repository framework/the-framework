Told to an agent that runs outside a checkout The Framework created — a plain terminal run in the user's own checkout, a GitHub Actions runner, a cloud session — in place of the branch-management skill: the command is not there, so the agent creates and checks out its `agent-<session name>` branch with git itself, works on it, and commits as it goes, since only what it committed is published and nothing is committed on its behalf.
