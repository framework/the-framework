The suggest-new-tickets preset: one line asking the agent to suggest new tickets and to write each one with the `tickets` skill's command, in the ticket format the skill gives. It is deliberately bare because the dashboard prefills it into the prompt box for the user to edit freely — the preset is a starting point for the user's own wording, not a finished instruction.
