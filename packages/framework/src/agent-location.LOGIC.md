Names where an agent's [1] turns executed, as an agent's record says it: `local` (this machine), `actions` (a GitHub Actions runner) or `web` (a Claude Code cloud session). An agent started today is local. The other two are read off records of agents from before the launcher started agents through the project's start hook, and off the cloud work the bridge still adopts. It carries no rule of its own: only the three names, shared by the store and the dashboard.

## Glossary

[1] agent: the unit of work: one task worked by a coding agent in its own checkout, on its own branch. The Framework starts none itself: the tool the project's start hook names runs it, and the dashboard shows it from the files that tool keeps.
