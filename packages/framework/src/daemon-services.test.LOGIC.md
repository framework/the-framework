What the tests cover, with the registry and the agent queue read off disk from a real `agent-data` branch and only the agent's process stubbed:

- **The concurrency setting is the size of a drain's fan-out** - with Auto PM on and the setting at four, the start-up sweep starts four agents, not the shipped default and not the queue's length; each is pinned to one open entry in queue order ("Work on this one open entry of the agent queue only"), started unattended, handed off at `merge` because the drain lands its own pull requests, not marked as a plan agent, and carries the ticket its entry links to, so four agents land in four lanes; the sweep's report says "started 4 agents"; the claim committed ahead of the first agent sits on the `agent-data` branch and names the agent id the agent is started with.
- **"Run now" with the schedule off** - with Auto PM off the start-up sweep starts nothing; the drain's "Run now" then fans out to the setting, each agent pinned to its own entry in queue order.
- **Retiring a drained entry** - once the agent's record says done with its handoff reported done, the entry is deleted from the queue as a commit on the `agent-data` branch ("queue done: <entry>"), while the untouched entries stay exactly as written; an agent whose handoff failed leaves its entry open for the next drain.
- **A claim on a ticket whose file is gone** - a drain whose entry links to a ticket file no longer on the branch still claims and starts, recreating the `tickets/` directory for the claim, instead of standing the batch down as already claimed.
- **The data-sync error** - a project whose `agent-data` branch has no remote carries a "data-sync" project error saying "no remote", also said on the daemon's log; once a remote exists and a sync converges, the error is gone rather than reworded.
- **The quota gate is the model's week** - with most of the account's week left but the week of the model the agents would run on fully spent, the sweep starts nothing and its report names the window that stopped it ("Current week (Fable) is 100% used"); the same spent model week does not stop a batch on another model with allowance left, and those agents start on the model the gate was measured for.
