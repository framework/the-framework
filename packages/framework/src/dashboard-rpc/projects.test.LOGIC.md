What the tests cover, against the real project [1] registry:

- **A project's recorded faults ride on the projects list** - a project the daemon's background work has recorded a fault against comes back with that fault, its code, its message and the time it was first seen; a project with nothing wrong carries no faults at all, rather than an empty list; the local only note rides the list the same way, with its reason (`no-remote` or `kept`), present only while it is set.
- **The records switch** - against a real repository: the read answers `no-remote` with no remote and nothing for an unknown project; turning sharing on with no remote is refused with "this project has no remote to share with" and leaves the setting unset; the read answers `kept` once a remote is added; turned on, the read answers `origin` and the remote holds the `agent-data` branch at once; turned off, `kept` again; with a remote that refuses the push, turning it on answers the failure ("could not be pushed") and the read is back to `kept`; an unknown project is refused with "this project has no local path on this server".
- **Adding hands the answer on** - the add hands the daemon the trimmed path and the person's answer on the records, as a yes only when it is exactly yes; an empty path is refused with "a project path is required".
- **Removing hands the id on** - the removal hands the daemon the project's id and answers what the daemon answers, a removal and a refusal alike; an empty id is refused with "a project id is required" and the daemon is not asked.
- **The branches an agent can start from** - against a real repository: the launcher's read names origin's default branch and the branch the project's folder is on, the same name twice when the folder is on the default branch itself; it names neither when the repository has no remote, when the start line does not mention `BASE` (a line that mentions `BASELINE` does not count, a person's own line that mentions `$BASE` does), and when the folder is on no branch; a project with no hooks file answers no start hook and no branches, and an unknown project answers nothing.

## Glossary

[1] project: a repository the user registered in the dashboard, identified by an id derived from its path.
