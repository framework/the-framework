What the tests cover: the "Run now" sweep waits for the sweep to actually run before answering, and reports the outcome lines that sweep decided — not a bare acknowledgement. A sweep that fails is reported as a failure; a sweep that ran but whose outcomes cannot be read is still reported as having run, so the card can say so instead of implying nothing happened. The narrowing the user picked — one routine, a routine named by the lock it holds, a single project, or nothing at all — reaches the sweep exactly as given.
