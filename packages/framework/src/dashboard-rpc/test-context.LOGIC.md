The world the call tests run against: the daemon's wiring with every capability present, as the one dashboard host would have it, so a test can call a read or an action directly. Starting an agent and adding a project both refuse ("not wired in this test"); the event source answers nothing, so every agent's stream comes off disk; no agent is relayed to a device; the preferences read and write the real registry file, which each test points at a throwaway directory; the quota reading is the real poller's; no project has recorded errors; and the bridge browser is off. A test overrides only the parts it cares about, and the wiring sticks until the next test replaces it. The same wiring is also offered in the shape the dashboard's HTTP server takes, so a test of one route stands up the same server the product does.
