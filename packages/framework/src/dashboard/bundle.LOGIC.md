Locates the built dashboard for the daemon to serve: the one directory `dist/dashboard-bundle` under the framework package, which counts as present only when its `index.html` exists, and which resolves to the same directory whichever copy of the code is running (built, test build or source). When it is absent the daemon has nothing to serve and answers every request with 503 "the dashboard bundle is not installed", by the rule in `server.ts`.
