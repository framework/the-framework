The entry point of the dashboard subsystem, imported by the daemon and the CLI: it re-exports, and carries no logic of its own, starting the dashboard's HTTP server (`server.ts`), the project summaries and the projections behind the pages (`projects.ts`, `overview.ts`, `dashboard.ts`, `queue.ts`, `tickets.ts`, `docs.ts`), the reads of git state, GitHub, file diffs and file contents (`git-status.ts`, `gh.ts`, `file-diff.ts`, `file-read.ts`), the handoff summary and pull request opening (`agent-handoff.ts`), the two notification feeds and their engine (`interventions.ts`, `activity.ts`, `keyed-watcher.ts`), the open questions (`open-questions.ts`), the Claude web bridge's endpoints and stores (`bridge-*.ts`), the web-start endpoints (`web-start-endpoints.ts`), the bundle and static file serving (`bundle.ts`, `static.ts`, `rpc-serve.ts`), and the types that go with them.
