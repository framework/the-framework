The single entry point to the dashboard subsystem: it gathers everything the rest of The Framework is allowed to use from the dashboard — starting the dashboard server, the project and overview summaries, tickets, the agent queue, git and GitHub status, file reads and diffs, the handoff, interventions, open questions, activity and the Claude web bridge — into one place. It carries no business logic of its own.
