What the tests cover: how the interventions list reads when posted to Discord.

A single open pull request is announced with its number, title, project name and link. A parked agent is announced with its question, the words "awaiting your answer" and the dashboard link, and never a pull request number. Unpushed work is announced with the task, how many commits are waiting, the branch they sit on and that they were never pushed — again never a pull request number — and the commit count is written in the singular when there is exactly one. Several items are summarised under a count of how many need the user, and an empty list posts nothing at all.
