What the tests cover:

- **Open pull requests across projects** - every project's open non-draft pull requests roll up into one list, newest first, a draft is left out, a project with no open pull request contributes nothing, and nothing open anywhere yields an empty list.
- **Reading a project whole** - a project whose pull request read fails is skipped and not counted as read whole while the others still are; a project that answers with nothing is read whole; a project whose live agents cannot be read still shows the pull requests it did read but is not read whole.
- **One pull request registered twice** - a pull request seen through two projects on the same repository appears once.
- **Agents parked on a gate** - a running agent with an unanswered gate becomes an item carrying the question's title and the gate's id; a gate left on an agent that is no longer running is ignored; the item links to the dashboard URL when known and is empty otherwise; pull requests and parked agents sort together newest first.
- **Identity** - a pull request's identity is its URL; a parked agent's is the project, the agent and the gate, so two agents on their identically named first gate stay distinct; unpushed work's is the project and the agent, distinct across agents and never colliding with a parked agent's identity.
- **Unpushed work** - a finished agent with unpushed commits becomes an item titled by what was asked (not the branch name), naming the branch, the commit count and the agent; nothing is surfaced when the work was already pushed, already merged, the agent wrote nothing, the branch is gone, or there is nowhere to push; a still-running agent is not unpushed work; an unreadable branch is skipped rather than failing; only the most recent finished agents by start time are inspected, up to the configured limit.
- **Drafts** - an agent's own draft pull request (on an `agent-` branch) reaches the feed while a hand-made draft does not; a draft with no head branch recorded is treated as hand-made.
