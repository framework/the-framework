What the tests cover:

- **Open pull requests across projects** - every project's open non-draft pull requests roll up into one list, newest first, a draft is left out, a project with no open pull request contributes nothing, and nothing open anywhere yields an empty list.
- **Reading a project whole** - a project whose pull request read fails is skipped and not counted as read whole while the others still are; a project that answers with nothing is read whole; a project whose live agents cannot be read still shows the pull requests it did read but is not read whole.
- **One pull request registered twice** - a pull request seen through two projects on the same repository appears once.
- **Agents parked on a gate** - an agent that ended `waiting` becomes an item carrying the title and id of the question its diary shows open, and only that agent's diary is read; an agent that is not waiting, a question answered since, and an unreadable diary give no item; pull requests and parked agents sort together newest first.
- **Identity** - a pull request's identity is its URL; a parked agent's is the project, the agent and the gate, so two agents on their identically named first gate stay distinct; unpushed work's is the project and the agent, distinct across agents and never colliding with a parked agent's identity.
- **Unpushed work** - a finished agent with unpushed commits becomes an item titled by what was asked (not the branch name), naming the branch, the commit count and the agent; nothing is surfaced when the work was already pushed, already merged, the agent wrote nothing, its commits change no file, the branch is gone, there is nowhere to push, or the branches provider did not answer for the branch; a still-running agent is not unpushed work; a provider read that fails gives no item and the project is not read whole; a project with no branches provider has nothing unpushed and is read whole; only the most recent finished agents by start time are inspected, up to the configured limit, and their branches are asked for in one read.
- **Unpushed work without an ask** - an agent whose record carries no ask is titled by the name the provider answers for its branch, else by the branch as it is.
- **Drafts** - an agent's own draft pull request reaches the feed, the branch being one a finished agent's record names or a working agent's checkout is on, while a draft on a branch no agent is on, and a draft with no head branch recorded, are treated as hand-made.
