What the tests cover, for the models source:

- **Asked once, then kept** - two reads at the same moment and a later read all answer each coding agent's models while each coding agent is asked once.
- **A coding agent that could not say** - its reason is the answer, with no models, and it is asked again at the next read, which then answers its models.
- **No way to list** - a driver without a way to list its models answers "this agent cannot list its models".
