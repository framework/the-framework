- **The settings in force** - of five projects, in order (one with a settings file but no subagents hook, one with the hook and no file, one with the hook and a file that does not parse, one with the hook and Claude Code on `opus` for hard tasks and 2 at once, one more with the hook and other settings), the settings are the fourth project's and `hooked` is 4; the first three alone give no settings and `hooked` 2; no project gives no settings and `hooked` 0.
- **Only the promised shape is kept** - an unknown coding agent, a blank model (the coding agent kept), a limit of 0, a level that is text, a limit of 2.5 and a value that is a list each read as unset; a model with spaces around it is trimmed.
- **Saving** - every project's hook is run with the same settings, cut to the promised shape (an unknown coding agent and an unknown field dropped), a project without the line skipped, and the answer is success; with only a project without the line, the answer is "no project has a subagents hook in .the-framework/hooks.yml"; a line that fails makes the answer "<project name>: <why>".
