What the tests cover, through the same RPCs the dashboard calls, the project's own start hook, and a real detached agent process with the fake driver in the coding agent's seat:

- **Starting an agent and watching it live** - the start hook was handed the prompt and the user's picks (driver and model) in its environment, and the id it answered is the agent's; the live feed, tailed from the moment of the Start, before the agent's checkout exists, carries the agent's reply and then its end.
- **The finished row** - the sidebar row settles to done carrying the prompt as its label, the branch the work is on (`agent-<id>`), and the driver and model the agent's card names.
- **The checkout is reclaimed, the work is on the remote** - nothing is left on the Remove list, the agent's branch is on `origin`, and the agent has no checkout of its own any more.
- **The recorded replay and the cross-project surfaces** - the recorded diary replays what the live tail told; the activity feed lists the agent as finished and names its project as read whole; the recent-agents list carries it; the handoff panel reports the branch pushed.
- **Two agents at once, each in its own checkout** - two agents started back to back are both working at the same time, both rows show as running, each names its own checkout under `.branches/` and the two differ; each then goes on and finishes on its own.
- **No start hook, and a hook that fails** - the launcher's read says whether the project has a start hook; a hook that fails answers its own stderr line; with the hooks file removed the read says no start hook, a Start answers "this project has no start hook", and nothing was started.
