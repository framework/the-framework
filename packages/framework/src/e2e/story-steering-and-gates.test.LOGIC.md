What the tests cover: everything the user does to an agent reaches it through what its tool reads — the inbox in its checkout while it works, the project's resume hook once it has ended, a signal to the process its card names — and the observable answer comes back through the agent's own diary.

- **Answering a waiting agent's question** - an agent whose turn ends on a question ends waiting, keeps its checkout, shows the question whole on its feed, and is listed in the cross-project questions hub with the same options; a pick that is not one of the options is refused; picking an option hands the project's resume hook the agent's id and the chosen label, the same agent goes on to done with the answer in its resumed turn, and it is gone from the hub and no longer answerable.
- **A message** - said to an agent that is certainly working, it waits in the agent's inbox, no hook runs, and it becomes a turn of its own; said once the agent has ended, the resume hook continues the same agent with the text, and the agent stays one row.
- **Stopping, and the checkout afterwards** - a stop ends a working agent as stopped, not failed; its checkout is reclaimed once its work is on the remote, so nothing is left on the Remove list and the agent no longer has a checkout of its own, while its row survives; deleting the agent then removes the row.
- **A waiting agent's kept checkout** - it shows on the Remove list, can be removed by hand, and the agent's row survives, still waiting.
