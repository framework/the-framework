What the tests cover: everything the user does to a live agent flows from the browser through an RPC into the agent's control file, and the observable answer comes back through the agent's own event stream.

- **Answering a parked agent's question** - a gate reaches the event stream whole (its title, at least two options, a recommended one), and the cross-project open questions list names it against the agent and its project with the same options; picking the recommended option records the pick and that the user made it, and the agent carries on to done; an answered gate is gone from the list.
- **Live chat** - a message sent while the agent is parked on a gate is held until the gate is answered, then becomes the agent's next turn, its text visible as that turn's prompt on the event stream; what was said survives the agent: the archived event stream carries the message.
- **Rearming the handoff mid-run** - setting the handoff level to `local` while the agent runs is announced as a handoff-armed event with push and pull request off, and the agent's record a reloaded tab reads reflects it.
- **Stopping, and the checkout afterwards** - stopping a parked agent ends it as stopped, not failed; its checkout is reclaimed once its work is on the remote, so nothing is left on the Remove list and the agent no longer has a checkout of its own, while its row survives as stopped; deleting the agent removes the row from the dashboard.
