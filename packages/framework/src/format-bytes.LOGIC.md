Renders a byte count as a short label for the dashboard (`1536` becomes `1.5 KB`): the largest unit from bytes to terabytes that keeps the number readable, with one decimal only when the number is below 10 and the unit is above bytes, so "how much would removing this give back" is answerable at a glance. A count that could not be read — absent, negative, or not a number — renders as an en dash by default, or as whatever placeholder the caller asks for, never as a zero that would read as a real size.
