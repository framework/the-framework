Names the directory under a project's root that holds The Framework's own files: `.the-framework`. It is one constant on its own, so every module that reads or writes there (the hooks file, the project's saved prompts, the `.gitignore` the activation writes, an agent's card, diary and inbox, the cloud scratch sweep's memory) spells the name the same way. Nothing of the product rides on a branch of its own: the lasting records — the `logs` skill's runs — live on the shared `agent-data` branch, and what sits under `.the-framework/` in a checkout is transient.
