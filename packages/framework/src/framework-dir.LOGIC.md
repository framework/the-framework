Names the directory under a project's root that holds The Framework's own files: `.the-framework`. It stands alone with no dependency on Node because the dashboard needs the name too, to build the file paths of the presets it renders in the browser (`.the-framework/presets/<name>.md`). Nothing of the product rides on a branch of its own: the lasting records — the `logs` skill's runs and the routine locks — live on the shared `agent-data` branch, and what sits under `.the-framework/` in a checkout is transient.
