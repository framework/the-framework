The package's entry point exports only types: the vocabulary the dashboard's browser code reads the daemon's answers as (agents, quota, preferences, tickets, the agent queue, open questions, the bridge and the rest), gathered in one place so a dashboard file imports its names here instead of from two dozen modules. Nothing imports the package by name and no value is exported, because a value would pull its defining module into the browser bundle; the browser gets its values from `client.ts` and its data over the dashboard's RPC calls. Every name here is imported by a file under `dashboard/`, and a name nothing renders is removed.
