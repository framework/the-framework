The one file-system adapter every store in the package builds on — read, write, append, "is this a file", "is this a directory", recursive directory creation, listing a directory's entries, listing its subdirectories, atomic rename, and setting permission bits — with forgiving reads: a missing or unreadable directory lists as empty, a path that cannot be inspected reads as neither a file nor a directory, and a symbolic link never counts as a subdirectory. Each consumer takes only the operations its own contract allows (the registry may not append, for instance), and the Node file-system module is loaded only when an operation runs, so modules that read files stay reachable from browser-safe code as long as the read itself never runs there.
