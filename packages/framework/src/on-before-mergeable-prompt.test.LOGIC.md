What the tests cover:

- **The shipped template** - the prompt declares its "TODO_FILE" macro as the agent queue's file, `TODO_AGENTS.md`, exactly as the `queue` skill names it; it carries a "## Maintenance" section whose entries reference the maintainability and security-audit preset paths; it carries a "## Business knowledge" section naming every business-knowledge document the built-in system prompt lists for reading, so an agent is never told to read one set of files and update another.
- **Flat placeholders** - no placeholder of the template nests another, because a nested one would stop the whole prompt from rendering at run time.
- **Rendering** - the rendered prompt has no placeholder left; each queued entry carries the session name and names the real preset file ("Apply .the-framework/presets/maintainability.md with tf.params.what set to "changes introduced by add-oauth"", and the same for `security_audit.md`); the readability preset is never mentioned; the same input always renders the same text.
- **A missing session name is refused** - rendering without a session name fails with an error that names the session name, rather than queueing entries about "changes introduced by undefined".
