Fixes the key scheme for the state the daemon keeps per project: an entry about one agent is keyed `<project key>::<agent id>`, and an entry scoped to the whole project (a project's preview, an agent with no checkout of its own) is keyed by the bare project key. The same scheme reads a key back into its two halves and tells whether a key belongs to a project, so every part of the daemon that keys its state this way agrees on the encoding.
