Turns a driver's session link into a real URL for the agent's driver session: a link template carries the placeholder `{sessionId}`, replaced by the session id once the coding agent reports one, while a link without the placeholder is a literal URL used as is. The generic entry point `https://claude.ai/code` is not a link into any one agent's session, so it is only ever offered as an "Open Claude Code" affordance; a real link to a live session comes from an explicit session link the driver reports.
