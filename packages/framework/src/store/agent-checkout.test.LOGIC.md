What the tests cover, against a throwaway project directory on disk:

- **The diary a tail follows** - no agent id, or a traversal-shaped one, has no diary; an agent with a checkout under `.branches/` resolves to the diary inside it; an ended agent whose checkout is gone resolves to its recorded diary on the `agent-data` branch, under whichever person's directory it is filed; a checkout beats the record, as for a resumed agent; an agent started a moment ago, with no checkout and no diary yet (even when its card is already on the branch), resolves to where its diary will appear in its checkout.
