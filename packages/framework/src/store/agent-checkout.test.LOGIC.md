What the tests cover, against a branches provider and a runs provider held in memory:

- **The checkout an agent id resolves to** - the checkout the branches provider lists for the agent; the project root when it lists none, when the project has no provider, for no id and for a traversal-shaped id; an agent missing from the provider's shared list is asked for once more, fresh, and found.
- **The diary a tail follows** - no agent id, or a traversal-shaped one, has no diary; an agent with a checkout resolves to the diary inside it, a checkout beating the record as for a resumed agent, and with no runs provider the checkout's diary file is still the answer; an ended agent whose checkout is gone resolves to the finished agent's lines from the runs provider; an agent started a moment ago, with no checkout and no finished record yet (even when its record already says `running`, and in a project with no branches provider), is "nowhere yet", so the tail asks again.
