What the tests cover, against a throwaway project directory on disk:

- **The diary a tail follows** - no agent id, or a traversal-shaped one, has no diary; an agent with a checkout under `.branches/` resolves to the diary inside it; an ended agent whose checkout is gone resolves to the finished agent's lines from the runs provider; a checkout beats the record, as for a resumed agent, and with no provider the checkout's diary file is still the answer; an agent started a moment ago, with no checkout and no finished record yet (even when its record already says `running`), resolves to where its diary will appear in its checkout.
