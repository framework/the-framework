What the tests cover: reading checkouts and acting on branches through a branches provider, with real processes — a small provider command in a throwaway project that answers each command line from a file and logs every call.

- **Which command provides** - a project whose dependency declares no branches provider has no checkouts; one whose dependency declares its command is read through it.
- **Each command line** - the list (with and without sizes), the state of several branches in one call (nothing is run when no branch is named), a push by branch name (a branch only the remote has answers `pushed` false), a removal with and without `--discard` (the branches that went with the checkout ride along); a push or a removal the provider refuses answers the provider's own line; an unsafe id never reaches the command.
- **Reads are shared** - two reads at the same moment are one call; a read within five seconds is not a call; a fresh ask within a second of a read is that read, past a second it runs again; a write and being told the project changed run the command again; a provider printing no JSON is no checkouts, and that failed read is not kept for the window.
- **The shapes** - a checkout needs an id and a path, a state needs a branch and its three verdicts; fields of the wrong type are dropped and the rest read as printed.
