What the tests cover: reading a project's pull requests and acting on them through a forge provider, with real processes — a small provider command in a throwaway project that answers each command line from a file and logs every call.

- **Which command provides** - a project whose dependency declares no forge provider has no forge; one whose dependency declares its command is read through it.
- **Each command line** - the pull requests with no flags and with a branch, a state and a time (a row without a number, a link and a known state is dropped); a listing the provider refuses answers the refusal's line, not an empty list; an open that returns a new pull request and one that returns the open one the branch already had (`existing`); a merge that arms, and one the provider refuses, answered with the provider's own line; the project's page with its link and name; every call reaches the command with exactly the arguments the contract names.
- **The provider is looked up again** - within five seconds the same source is reused; after five seconds the same command still providing keeps the source; being told the project changed after the package is dropped answers no forge.
- **The shapes** - a pull request needs a number, a link and a state spelled `open`, `merged` or `closed`; missing text fields read as empty; anything that is not a list is no pull requests.
