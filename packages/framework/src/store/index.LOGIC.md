The store's entry point: what the daemon and the dashboard RPCs import to read agents — the reads of `agent-store.ts`, the resolution of an agent id to its checkout and its diary (`agent-checkout.ts`), the runs provider, the card and diary's shape and the shared reads (`runs.ts`), the queue provider and an entry's shape (`queue.ts`), the branches provider with the shapes of a checkout and a branch's state (`branches.ts`), the git host provider with the shapes of a pull request and the project's page on the git host (`git-host.ts`), the forgetting of all of them after a widget's command (`provided.ts`), the mapping from the card and diary to what the dashboard draws (`run-record.ts`), and the conversion between an agent id and its start time (`../agent-id.ts`). It carries no logic of its own.
