Reads the project's own `SYSTEM.md` from the root of the agent's working directory: its content trimmed of surrounding whitespace, or nothing when the file is absent, unreadable or blank, in which case the built-in system prompt stands alone. This is the one part of the system prompt that touches the disk; it is kept apart from the composition in `system-prompt.ts` so that composition can run in the browser, where the dashboard shows the prompt before an agent starts.
