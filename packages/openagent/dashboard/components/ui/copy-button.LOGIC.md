Provides the small copy-to-clipboard button placed beside strings the user takes to a terminal, such as branch names, session ids and URLs. A click writes the host's text to the clipboard; once the write has landed, the copy icon turns into a green check and the tooltip reads "Copied" for 1.5 seconds, then both return to the copy icon and the host's label, so the user sees that the click worked and can copy again at once. The button is announced by the host's label, which is also its tooltip. When the browser offers no clipboard, or refuses the write, nothing changes: no check, no message.
