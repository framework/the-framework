The subscription to the live stream of one agent's events, kept beside the call stubs so that everything the dashboard reaches the daemon for sits in one directory. It is not a call: a stream has its own endpoint and its own client, which is `lib/rpc.ts`'s (one subscription per selected agent, every event delivered as it is written, a clean end told apart from a dropped connection), and this file only re-exports that subscription under the name the pages use. Which agent's events are streamed, from where, and how the replay is marked is the daemon's logic, described beside `src/dashboard-rpc/events.ts`.
