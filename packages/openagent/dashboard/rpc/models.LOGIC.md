The browser's typed stub for the agent and model menu's one call: which models each coding agent [1] offers, as the daemon asked them, or, for a coding agent that could not say, why. The call is addressed by its name over the dashboard's transport (`lib/rpc.ts`) and declared with the daemon's own signature for it, taken from `src/dashboard-rpc/models.ts`, so a renamed or re-shaped call is a type error in the dashboard's build; none of the daemon's code reaches the browser bundle.

## Glossary

[1] coding agent: the CLI doing the actual work: Claude Code or Codex.
