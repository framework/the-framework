Runs a call about one agent locally, or relays it to the device that runs the agent: when the agent id names an agent this daemon relayed to a device, the call — its name and its arguments — is forwarded to that device over the device's saved token and the device's answer is returned; for any other agent the local answer is computed unchanged. A device that cannot be reached answers the same empty or error shape the local read gives on a failed read, so no caller ever special-cases a relayed agent.
