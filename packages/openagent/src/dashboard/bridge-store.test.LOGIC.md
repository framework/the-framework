What the tests cover:

- **An answer names only what the session offered** - queuing is refused for a session with no parked question; a label that is not one of the question's options is refused, alone or beside a valid one; a single-select refuses none and refuses several, and takes exactly one; the queued answer is then pending with its labels.
- **What gets typed** - the text is the continuation a local gate re-prompts with, `You paused to ask: "<title>". The user chose: <label>. Continue with that decision.`; a multi-select joins the picked labels with commas, reads "(none)" for an empty pick, and refuses a label named twice; an option marked to stop yields the takeover wording, "Stop here: the user is taking over and will come back with fresh instructions.", while any other pick continues.
- **A delivered answer resolves the question** - after a successful delivery the question is gone, the answer reads as sent and nothing is pending; a re-report of the same question does not resurface it; a genuinely new question does surface and clears the resolved answer with it.
- **A failed delivery keeps the question** - the question stays parked, the answer reads as failed with the extension's note, and a new pick replaces the failed attempt.
- **Withdrawal** - a queued answer can be withdrawn and is then gone; a delivered one cannot and stays sent.
- **Stale acknowledgments** - an acknowledgment naming an earlier answer's id does not resolve the newer queued one, which stays queued with its question parked.
- **An undelivered pick dies with its question** - when a new question replaces the parked one before the extension collected the pick, nothing is pending anymore.
- **Waiting on a human** - a session is not waiting by default; a list status of "awaiting" makes it waiting and is readable; a newer status replaces the older, so "idle" ends the wait; a parked question makes the session waiting whatever the list said; forgetting the session ends both the wait and the status; a list status older than the 12-hour window no longer marks the session waiting.
- **One Driver tab at a time** - the first Driver tab asking gets the answer and a second asking a second later gets nothing; the dashboard still sees the answer queued and cannot withdraw it; once the 90-second claim expires the same answer is offered again, and a withdrawal succeeds again once no claim holds it.
