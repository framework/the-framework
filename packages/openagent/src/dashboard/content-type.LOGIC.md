Maps a file's extension to the content type the daemon sends with each file of the dashboard bundle: HTML, JavaScript (`.js`, `.mjs`), CSS, JSON, SVG, icons, PNG, JPEG, GIF, WebP, the WOFF font formats, source maps and the web manifest, matched case-insensitively; any other extension is served as a generic binary stream (`application/octet-stream`). One table, so every static file handed out by `static.ts` is labeled the same way.
