The routine skills: one folder per routine, each holding the `SKILL.md` the daemon fires, marked so that only a person or the daemon invokes it. Its body is the job's prompt: the daemon starts the agent with the skill's slash command and the coding agent's harness expands it.

- **Working the queue** (`work-queue/`) - one queued task off the agent queue, unattended; the routine The Framework's daemon fires when the `agent-data` branch moved (the rules in `packages/framework/src/auto-pm.ts`).
