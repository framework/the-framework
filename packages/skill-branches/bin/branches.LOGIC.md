The `branches` executable, the one an agent finds on its PATH and a person runs as `npx branches`: it hands the process's arguments, working directory and streams to the command (whose rules are in `src/cli.ts`), prints each JSON document on stdout and each line for a person on stderr, and exits with the command's code: 0 for a result, 1 for a refusal or a git failure, 2 for a command line that could not be read. A crash the command did not account for is printed on stderr and exits 1. It runs the package's built code, so in a workspace checkout of this repository the package must be built before the executable works.
