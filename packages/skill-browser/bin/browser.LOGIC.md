The executable behind `npx browser` and the `browser` on the agent's PATH: it hands the shell's arguments, the current directory, the environment (which carries `AGENT_DIARY` when the tool running the agent keeps a diary) and the two output streams, one line at a time, to the command in `src/cli.ts`, and exits with the code the command answers: 0 when done, 1 for a refusal, 2 for a command line that could not be read. A failure the command did not catch is printed to stderr and exits 1.
