The entry the `browser` command starts, detached, when a project has no browser open: it reads the state file's path, the Chrome to run and the idle time from its command line (`--state`, `--chrome`, `--idle-ms`), and the diary's path from `AGENT_DIARY` in its environment, which it inherits from the agent's own environment when the tool running the agent keeps a diary; it then runs the browser's process by the rules of `host.ts`, with no diary when `AGENT_DIARY` is unset or empty, and exits once that process has ended.
