The package's entry point: the `browser` command's runner with its usage text, the rule naming a directory's project, the rule naming a project's state file, and the 30-minute idle time (`cli.ts`), plus the shape of the screen line the browser's process writes into the agent's diary (`host.ts`). No program in this repository imports it today: an agent runs `browser` through `npx`, and the dashboard reads the screen line off the diary with its own copy of the shape.
