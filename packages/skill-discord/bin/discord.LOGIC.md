The executable behind `npx discord` and the `discord` on the agent's PATH: it hands the shell's arguments, the environment (which carries `DISCORD_WEBHOOK` and `XDG_CONFIG_HOME` when they are set) and the two output streams, one line at a time, to the command in `src/cli.ts`, and exits with the code the command answers: 0 when done, 1 for a refusal or a failure, 2 for a command line that could not be read. A failure the command did not catch is printed to stderr and exits 1.
