The package's entry point: the `discord` command's runner and its usage text (`cli.ts`), plus the webhook's rules (`webhook.ts`): the `DISCORD_WEBHOOK` name, the 2,000-character limit and the cut, the saved webhook's file path, which webhook a message goes to, a webhook's shape check, and the one POST. Saving and forgetting the saved webhook are not exported: only the command does them. No program in this repository imports it today: a person, an agent, or a tool's line runs `discord` through `npx`.
