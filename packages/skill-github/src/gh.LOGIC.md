The one way this package runs `gh`, GitHub's command line: `gh` on PATH, with the working directory given, a minute per call since every call reaches the network; the standard output is the answer, and a failure is gh's own standard-error line (its exit message when gh printed none). Every other file takes the runner as a parameter, so a test scripts GitHub's answers and the code is the same either way. Nothing outside this package runs `gh`.
