The project's page on GitHub, for the dashboard's project bar link: `https://github.com/<owner>/<repo>`, derived from the `origin` remote in its scp (`git@github.com:o/r.git`), ssh (`ssh://git@github.com/o/r.git`) or https (`https://github.com/o/r.git`) form, a `.git` suffix, an embedded credential and a trailing slash dropped; nothing for a remote on another host, for a slug that is not `owner/repo`, or for a repository with no `origin`. The git host's name, "GitHub", is answered beside it, so the dashboard labels the link without spelling the host.
