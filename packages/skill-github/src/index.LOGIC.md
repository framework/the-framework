The package's entry point, `@gemstack/skill-github`, with no logic of its own: the gh runner (`gh.ts`), the pull requests as one read (`requests.ts`), opening a request (`open.ts`), arming and landing a merge (`merge.ts`), the merge watcher (`merge-watch.ts`), the project's page (`home.ts`), and the `github` command run in-process (`cli.ts`). The dashboard's server and `agent-runner` import nothing of it: they run the command.
