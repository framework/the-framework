The `logs` executable, the command on every agent's PATH: it hands everything after the program name, the current directory and the two output streams to the command's runner in `src/cli.ts`, and exits with the code the runner answers: 0 for a result, 1 for a refusal or a git failure, 2 for a command line that could not be read. A crash the runner did not turn into one of those is printed to stderr and exits 1.
