The package's entry point: one import gives the product the run's shapes and rules (`run.ts`), the recording program's store operations on the `agent-data` branch's checkout (`store.ts`), the runner of the `logs` command (`cli.ts`), and where the executable and `SKILL.md` live for a program that starts agents (`bin-dir.ts`). Two programs consume it: the scheduler (`packages/agent-scheduler`) records each run it starts and ends, and the product (`packages/framework`) imports it only in its end-to-end tests: its pages read, patch and delete runs through the `logs` command. No program imports `bin-dir.ts` today: an agent runs `logs` through `npx`. A second entry point, `names`, exposes only the runs directory name, `agents`, for code that must not load Node modules.
