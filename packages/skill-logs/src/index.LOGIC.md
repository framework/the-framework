The package's entry point: one import gives the product the run's shapes and rules (`run.ts`), the recording program's store operations on the `agent-data` branch's checkout (`store.ts`), the runner of the `logs` command (`cli.ts`), and where the executable and `SKILL.md` live for a program that starts agents (`bin-dir.ts`). The product (`packages/framework`) is its consumer: the daemon puts the executable on every agent's PATH, lists the skill to the coding agent, records each run when the agent ends, patches the branch and the pull request onto it later, deletes it when the agent's records are removed, and reads runs and diaries back for its pages. A second entry point, `names`, exposes only the runs directory name, `agents`, for code that must not load Node modules.
