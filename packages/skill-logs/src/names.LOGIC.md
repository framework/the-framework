The branch's own name is not repeated here: the runs live on the shared `agent-data` branch whose name `@gemstack/agent-data` exports, a convention `SKILL.md` states to every agent rather than a setting. The value has no dependency on Node, so browser code names it too through the package's `names` entry point.
