The one name the package hangs off: the runs directory, `agents`, at the root of the shared data branch `agent-data` (named by `@gemstack/agent-data`, not here), under which each person's directory holds their runs. A convention, not a setting: `SKILL.md` names the same directory to every agent. Reachable on its own by code that runs in a browser and must not pull in git.
