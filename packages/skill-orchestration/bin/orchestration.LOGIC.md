The executable behind `npx orchestration`: it hands the shell's arguments, the working directory, the environment (which carries `AGENT_ID`, the calling run's id, when a run's agent calls it) and the two output streams, one line at a time, to the command in `src/cli.ts`, and exits with the code the command answers: 0 for a result, 1 for a refusal or a failure, 2 for a command line that could not be read. A failure the command did not catch is printed to stderr and exits 1.
