What the tests cover, through the command line, against a real git repository with run records written on its `agent-data` branch, at a fixed time; the runner's spawn of a run's process, its readiness check, the probe of a live pid and the stop signal are replaced, so no agent is started and no process is signalled:

- **Start** - from the checkout of a main agent on Codex, `start` spawns a run with the id minted from the time, the main agent as parent, the checkout's branch as base, the task followed by the subagent lines as prompt, on Codex, and answers the id, the driver and the base with nothing on stderr; `list` then already shows that subagent as `running` with its task, and `stop` on it answers `no-process`; `--driver` and `--model` named win and are on the record, and a branch the agent renamed is the base; a checkout with an uncommitted file answers `uncommitted: true`, says so on stderr, and still starts; a process that cannot be spawned fails the command with the spawn's error and leaves no record.
- **Start refused** - with `AGENT_ID` unset, and with `AGENT_ID` naming a run the project has neither a record nor a live card of, `not-a-run`, the stderr line saying to do the task itself; a caller known only by the live card in its checkout starts a subagent, and a recorded coding agent the runner cannot start becomes Claude Code; a coding agent that cannot start, `not-ready` with the problems, the problem as the stderr line; a checkout on no branch, and a caller whose directory under `.branches/` is not a checkout of its own, `no-branch`; a caller that is itself started for another run, `subagent`. Nothing is started in any of them.
- **List** - an empty array for a run with no subagent; then only the runs whose record names the caller as parent, newest first, each without `caller` and with the task in place of the prompt; a run started for another run is left out; `not-a-run` with `AGENT_ID` unset.
- **Read** - an ended subagent answers its card and, as `result`, the last `result` line of its diary, not an earlier one; a running one answers no `result`; another run's subagent, the caller itself, and an id of no run are each refused `not-yours`.
- **Stop** - a running subagent with no live card is refused `no-process`; with a live card whose pid is not alive, `no-process`; with a live card that says `done` and a live pid, nothing is signalled; with a running live card and a live pid, the stop goes to exactly that pid and the id is answered; an ended subagent is refused `not-running` with its status; a subagent on another machine, `other-machine`; a run that is not the caller's, `not-yours`, its live card and pid notwithstanding. Nothing is signalled in any refusal.
- **Usage errors** - no command, an unknown one, `start` with no task, a blank task, two arguments or an unknown driver, `list` with an argument, `read` and `stop` with none, and an unknown flag each exit 2 with the usage on stderr, nothing on stdout, and nothing started or signalled; outside a git repository, `list` is refused `not-a-repo`.
