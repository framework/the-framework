The executable behind `npx queue` and the `queue` on every agent's PATH: it hands the shell's arguments, the current directory and the two output streams to the command in `src/cli.ts`, and exits with the code the command answers: 0 for a result, 1 for a refusal or a git failure, 2 for a command line that could not be read. A failure the command did not catch is printed to stderr and exits 1.
