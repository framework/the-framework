The widget's one link action, "Add to queue", as the dashboard mounts it: the label "Add to queue" with a list-plus icon, "Queued" once done, and the act itself, which hands the links to the rule in `src/widget.ts` with the dashboard's host running this package's `queue` command in the link's project. Each link becomes one `queue add` of the line a queued link is written as, `[text](href)`, or the plain text when the link points nowhere, placed in its priority's section when the page gave a priority; the batch stops at the first failure. The action knows nothing of what a link names: a ticket, a plan, anything a page shows as a link.
