Tells the daemon three things about this package so it can hand the skill to every agent it starts: the directory holding the `queue` executable (to put on the agent's PATH), the skill's name `queue` (the name in `SKILL.md`'s front matter, and the directory a coding agent lists the skill under), and the package directory holding `SKILL.md`. The two directories are located beside the built code, so they are the same from a workspace checkout and from an installed package.
