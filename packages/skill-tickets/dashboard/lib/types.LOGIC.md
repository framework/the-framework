What the pages show as a ticket: the `tickets` command's row (file, title, summary, date, planned, and the optional priority, topics, GitHub link, pull request, effort, uncertainty, claim and holder), plus, when the claim names one of the project's runs, that run's id and session name, so the row can name and open it; one ticket with its whole text, for its own page; and one project's tickets with the project's id and name, for the cross-project list.
