What the widget's page tests stand the dashboard in with: a fake host whose commands answer from a table keyed by project and command line (a line with no answer fails, naming itself), whose acts answer the same way, and whose every other service — open a run, open a page, start a run (answering a started id), open the launcher with a prompt, the project's runs — is a spy; plus a way to render a page inside that host and inside whatever actions installed widgets offer on links (none by default). The host is handed over whole, so the pages under test never reach a real dashboard.
