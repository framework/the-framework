Global `<head>` additions: pre-paint package-manager restore script, Open Graph tags, and IBM Plex font loading.

## TLDR

- Inline script runs before first paint: reads `localStorage.pm` and stamps `document.documentElement.dataset.pm` (`npm|pnpm|bun|yarn`, defaulting to `npm`, try/catch-guarded) so the CSS-driven PM choice (`styles.css` + `Hero.tsx`) renders without FOUC.
- OG tags: `og:url` `https://the-framework.ai/`, `og:type` website, `og:image` `/banner.jpg` — the image is generated by screenshotting the `/banner` page (see `/press`).
- Google Fonts preconnects + IBM Plex Sans (400–700) and IBM Plex Mono (400–600) stylesheet.
