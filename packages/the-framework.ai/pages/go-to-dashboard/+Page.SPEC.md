The page the website's "Dashboard" link leads to. There is no hosted dashboard to send a visitor to — the dashboard runs on the visitor's own machine — so this page tells them how to open it from their terminal instead.

It offers three routes, each a click-to-copy command: run `the-framework` if The Framework is already installed, install it globally if not, or run it once without installing to try it out. The install and one-time-run commands are shown in the visitor's chosen package manager, picked from tabs for npm, pnpm, bun and yarn; the choice is the same one used everywhere else on the website and is remembered across visits.
