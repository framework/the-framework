The "Features" section: the product's capabilities as a grid of eight cards.

## Business logic — TL;DR

- **Bring your own subscription** - The Framework drives the user's own Claude Code or Codex installation, on the user's own AI subscription, the way a human would.
- **Optimal quota usage** - it spends the subscription's otherwise-wasted quota on autonomous work, aiming for maximum daily usage while leaving room for the user's own manual prompts.
- **Bring your own prompts** - saved prompts can be re-used quickly, kept private or shared with teammates.
- **Dashboard** - shows the pro-rated usage quota, the agents currently running, the queued tasks, the queue of reviews the user owes, the hot tickets, and more.
- **Notifications** - browser and Discord notifications when an agent finishes or needs the user.
- **Claude Code Web** - agents can run on Claude Code Web instead, using no local CPU.
- **Swarm of local computers** - agents can be spread across several of the user's own machines.
- **Discord bot** - a Discord bot for agentic team conversations.
