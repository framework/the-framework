The "Your framework" chapter, subtitled "It isn't our framework. It's yours.": three cards of promises. "Flexible": The Framework doesn't force anything, the user picks only the features they need; and, marked "Coming soon", customize anything to fit your needs. "100% Local": it runs locally on the user's machine like a desktop app; no backdoors, no tracking; memory is saved in the user's Git repository at `knowledge-base/*.md`; the data is fully theirs. "100% Open Source": transparent, no hidden code; and if something is not working, the user is invited to ask their favorite AI to make a pull request, since agentic contributions are welcome.
