The visual vocabulary the site's sections share, and the three addresses the whole site links to: the Discord server (`https://discord.gg/qc8zvdzWNR`), the GitHub repository (`https://github.com/framework/the-framework`) and the npm package (`https://www.npmjs.com/package/framework`). The shared pieces are the section column and its headings; the centered chapter heading with an accent bar and an optional subtitle; the "Note" callout, an italic aside with a yellow edge; the "Coming soon" badge that marks a feature the site announces before it exists; inline code chips; and emoji rendered as the site's own SVG images (💪, 🦾, 🧭, 🤖, 🙋, 😕, 🚀, 🚧) so that they look identical on every platform instead of depending on the visitor's emoji font.
