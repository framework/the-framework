The shared building blocks every page of the website is made of: the site's three outbound destinations (the Discord invite, the GitHub repository, and the npm package `framework`), plus the recurring visual pieces — a centered section heading with an optional subtitle, a highlighted note, an inline code chip, and a "Coming soon" badge that marks a capability the product does not ship yet.

Emoji are drawn from images shipped with the website rather than the visitor's own emoji font, so they look identical on every platform.
