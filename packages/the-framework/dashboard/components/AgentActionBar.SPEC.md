One agent's action bar: what the agent is on the left — its branch, state, and a summary of what the branch holds, as a disclosure — and what you can do to it on the right.

## TLDR

- The doing collapses into one overflow menu; only the handoff's next step (push / open PR) stays out as a visible button, since it is the one thing that moves the work forward.
- The agent's state (exactly one of stopped, ready for merge, failed, building, finished) reads beside the branch facts instead of spending a banner row on one word.
- One bar whether the agent is live or finished, and one row always: the label gives up width before the controls ever wrap.
