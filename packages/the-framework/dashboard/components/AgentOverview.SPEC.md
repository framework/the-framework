The at-a-glance summary of one agent, above its feed: its session name and single status word, the count of errors it hit with the latest headline, and a link out to the driver's own session.

Each part appears only once its fact has arrived, so an agent that has just started shows nothing extra, and an agent with none of the three shows nothing at all. The errors themselves stay in the log at the point where the agent hit them; only the count is kept here, where the log cannot scroll it away. The session link is labelled for what it actually opens: where the driver has no per-session address, it offers the driver's app rather than pretending to be a deep link to that session.
