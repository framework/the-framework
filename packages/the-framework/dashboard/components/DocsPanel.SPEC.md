Shows the planning documents an agent writes for itself — its PLAN and TODO files — rendered beside the agent so the user can follow the plan the agent is working to.

One document is shown at a time, picked from a row of buttons naming each document; the content is rendered as markdown. While the documents are still being fetched the panel says it is loading, and only once they have arrived does it say "No PLAN/TODO docs yet." — the two are different facts, and conflating them made a project that has documents flash the empty message every time it was opened.
