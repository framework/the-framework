The Overview's cross-project shortlist of the tickets that matter right now: what is being worked on, what sits in the AI Queue (the work queued for the framework to pick up on its own), and what is flagged high priority.

## Flows

- Three lanes, every qualifying ticket listed in full — never "+N more" — and the empty state names the lanes rather than claiming the backlog is empty.
- A ticket an agent is implementing right now says so — live work outranks the "planned" mark older work left behind — and its row opens that agent.
- A ticket with no agent opens its project's launcher — the start-an-agent composer — prefilled with a plain, editable "work on this ticket" draft naming the ticket file. The click is never a dead end, and the draft is the ask itself — no hidden second version to drift.
