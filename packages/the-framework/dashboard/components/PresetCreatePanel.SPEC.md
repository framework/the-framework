The "New preset" dialog: name and save a prompt as a reusable preset, prefilled with what is currently typed in the composer since the common path is saving what you just wrote.

## TLDR

- Saving needs both a name and a prompt.
- With a project open you choose where the preset lives: private to you on every project, or committed into the project's repo and shared with the team; with no project open it is always private.
