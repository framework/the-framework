The "New preset" dialog: name and save a prompt as a reusable preset, prefilled with what is currently typed in the composer.

## Flows

- Saving needs both a name and a prompt.
- With a project open the user chooses where the preset lives: private to them on every project, or committed into the project's repo and shared with the team; with no project open it is always private.

## Rationales

- The prefill serves the common path: saving what was just written.
