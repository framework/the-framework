What the tests cover: the Priority facet offers its named buckets with a count on each, a min–max slider below them, and a "No priority" row that is shown only when some ticket names no priority; the Effort and Uncertainty facets exist only once some plan recorded those numbers; the Topics facet lists topics case-deduplicated and busiest first; the Project facet appears only when more than one project is registered; and the Stage facet counts a claimed ticket as claimed even while it is also planned.

Bucket selections and the slider stay consistent: adjacent buckets read as one span on the slider, and only a selection that skips a middle bucket dims it and reads "not one span".

Clear appears as soon as any filter is on, resets every filter, and leaves the sort and grouping untouched. Picking a new sort key starts it at that key's natural direction, while re-picking the active key changes nothing; the direction pair sits in the same menu, is labelled by meaning ("Newest first", "Oldest first") with the applied one marked, and "Group by project" unticks into the flat cross-project list.

The `/` keycap advertises the search shortcut and steps aside once the field is focused, and pressing `/` on the page focuses the search field.
