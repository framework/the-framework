Tracks whether the browser has granted, denied, or not yet been asked for permission to show desktop notifications, reporting "unsupported" in browsers that offer no notifications at all. The answer is kept current by re-checking every few seconds, because not every browser announces a permission change and the user can flip the setting outside the dashboard.

The single shared answer serves both the notifications menu and the Onboarding checklist, which ask the same question and would otherwise each need their own re-checking.
