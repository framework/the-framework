The page layer: a single page owns every address, and the surrounding setup makes the whole app a client-only bundle behind one prerendered static shell — serving the dashboard is serving files, with all behavior in the browser talking to the daemon. The shell also carries the product's typefaces, title, and tab icon, so the dashboard shares the marketing site's identity.
