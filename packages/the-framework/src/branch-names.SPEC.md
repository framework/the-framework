The single place branch and checkout-directory names come from: sessions start on `tf-agent-<id>`, are renamed to `tf-<name>` once named, and each checkout directory is named as its branch — slash-free on purpose, so directories can carry branch names and cloud sessions can resolve them; the old slashed spellings are still recognized but never created.
