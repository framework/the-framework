Covers Claude Code's folder-trust record. Reading: trusted and declined folders, a never-seen folder reading as known-untrusted, and a missing or unintelligible record answering unknown. Writing: the trust entry lands while every other part of the CLI's config survives, a missing file is created, and an existing file that cannot be parsed is refused rather than replaced.
