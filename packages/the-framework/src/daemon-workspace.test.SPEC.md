Covers where a run is allowed to land and what happens when it dies: a repo whose worktree cannot be created refuses the start instead of borrowing the user's checkout, a child that dies at boot is marked failed with its actual error, transient connection deaths earn a bounded number of automatic continuations while real failures stand, and a logged-out agent is refused before any branch or worktree is spent.
