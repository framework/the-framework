What the tests cover: a preferences write that cannot be stored is reported as a plain failure the dashboard can render, rather than as a crashed request — both for a full save and for a partial one. A partial save answers with the complete merged preferences, which is what lets a stale tab adopt the current settings instead of overwriting them.
