Renders a byte count as a short human label (`1536` → `1.5 KB`, with a decimal only where it helps) — a size for a label, not a report, so "how much would removing this give back" is answerable at a glance. A size that could not be read (absent, negative, or not a number) renders as an en dash by default rather than a zero that would read as an answer.
