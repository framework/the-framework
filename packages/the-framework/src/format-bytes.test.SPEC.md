What the tests cover: a byte count is shown in the largest unit that keeps it readable, from bytes up to terabytes, with a fractional digit only where it adds meaning; and a size that could not be measured — missing, unreadable, or nonsensical — shows a placeholder (a dash by default, or whatever placeholder the caller asks for) instead of a zero that would read as a real answer.
