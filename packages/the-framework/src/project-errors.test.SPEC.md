Covers the per-project error state: an empty project lists nothing, a recorded error carries its kind, detail and first-seen time, a repeat report of the same kind refreshes the detail but keeps the first-seen time, clearing removes it (and a later report starts a fresh clock), and projects never see each other's errors.
