# Click `Import tickets from GitHub` => redirects to the wrong page (should redirect the running session)

## TLDR

Clicking the "Import tickets from GitHub" button (onboarding checklist, #958) redirects to the wrong page — it should redirect to the running session it just started. (Title-only issue — no description on GitHub.)

## Why it matters

The import button fires a real run; landing the user anywhere but that run's live session breaks the feedback loop right in the onboarding flow, where trust is being established. Small fix, first-impression impact.
