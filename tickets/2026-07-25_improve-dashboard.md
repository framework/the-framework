# Improve dashboard

## TLDR

Dashboard paper cuts from dogfooding: remove the "Everything the agent is doing, across every project." tagline; the onboarding circles look like radio buttons; the onboarding subtexts are hard to understand; it should be clear which onboarding items are optional. Thread adds: a view judged redundant (asking of each element: strictly needed? adding real value? important enough to show first?) and clicking the project name (`gemstack`) weirdly redirects to a new session — "We should probably re-haul this whole view."

## Why it matters

High priority: the dashboard is the product's face and these are exactly the "major UX paper cuts" the MVP roadmap (#538) calls out as crucial. The screenshots (on GitHub) pin each complaint to a concrete view; the closing line signals this may grow from paper-cut fixes into a rework of the overview.
