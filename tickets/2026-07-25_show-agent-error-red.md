# Show agent error msg in red

## TLDR

Agent error messages currently render like normal log text (screenshot in the issue) — show them in red. Only if quick-win, and only for AI to pick up autonomously.

## Why it matters

Errors that don't look like errors get missed; red makes failure states scannable in the session log. Deliberately scoped as a cheap AI-autonomy test balloon ("Let me try to get AI to auto work on this").
