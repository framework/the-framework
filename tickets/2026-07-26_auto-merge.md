# Auto-merge

## TLDR

New setting `[ ] Auto-merge`, default false. Should be set to `true` for some prompts, e.g. the "quick-win work" and "consensual work" routines.

## Why it matters

Closes the autonomy loop for low-risk routine work: without it, every routine-produced PR waits on a human even when the work was defined as consensual/quick-win. Labeled `highest-prio 🌟`.
