# Landing page: New feature "Headless browser"

## TLDR

Add a landing-page feature "Headless browser": The Framework launches a headless Chromium, giving agents full seamless access (e.g. DOM via Chrome MCP) — no need for an AI browser extension anymore.

## Why it matters

Agent-driven browsing without an extension is a real capability of the stack (see #469, browser phase 2) and a differentiator worth naming on the landing page (#538 MVP v3: "Landing page").
