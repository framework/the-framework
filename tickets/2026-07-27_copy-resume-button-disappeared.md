# Local run => button to copy `claude --resume` CLI command disappeared

## TLDR

The button that copies the `claude --resume` command for a local run is missing — or possibly was never merged. Thread narrows it: the button disappears after manually stopping the local run; across many sessions/runs some have it and some don't. Expected: the button stays visible at all times.

## Why it matters

Resuming a framework run in a plain CLI session is the escape hatch when the dashboard flow isn't enough; an inconsistently-present button reads as a regression and blocks that hand-off.
