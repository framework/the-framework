# SDD extension: @the-framework-ai/sdd (post-MVP)

## TLDR

Spec-driven development as an opt-in extension package, `@the-framework-ai/sdd` — not core. Sketch: humans own the specs, work is split into phases, each phase verified against the spec before the next. Explicitly post-MVP; not to be worked before the basics are rock-solid.

## Why it matters

Filed so the idea doesn't get lost (Rom's idea, Discord 2026-07-30, out of the #1132 Traycer discussion). Phase-plus-verify is exactly the workflow that runs against the core black-box stance (#1373) — packaging it as an opt-in extension keeps the core clean while still offering the workflow to teams that want it.
