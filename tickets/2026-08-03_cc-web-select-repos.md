# [CC Web] Select repos

## TLDR

When driving CC Web, select all available repositories by default (UX over safety for now) instead of making the user pick. If a repo isn't available (the user didn't add it in CC web), show an error in the UI.

## Why it matters

Removes a friction step from the CC-web path that's needed working ASAP for the YC demo. Caveat from the issue: if driving CC Web turns out too complex, polishing its UX (this ticket) can be deprioritized — but making it work cannot.
