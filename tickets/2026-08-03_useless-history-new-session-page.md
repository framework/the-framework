# Useless history in new session page?

## TLDR

The new-session page shows a session history whose benefit the maintainer questions — consider removing it. Specific gripes even if it stays: the explanatory caption is too wordy (aim for a clean, low-text UI like claude.ai/code); `STOPPED` reads as noise (show `DONE` or nothing); the `[Build]` tag is unexplained; and the sidebar history differs from the session-page history, which is confusing.

## Why it matters

The new-session page is the first thing a user sees when starting work; clutter and inconsistency there directly undercut the product's first impression.
