# Continue planning: resume the agent that made a plan

## TLDR

Plans get a new `## Agent` section holding how to talk to the agent that made the plan — either the CLI command to resume the Claude Code CLI session or the link to the Claude Code Web session. The plan page (e.g. `/…/tickets/<ticket>.md/plan`) gets a "Resume agent" button with a nice tooltip.

## Why it matters

Iterating on a plan currently means starting a fresh agent without the planning context; resuming the original session keeps it.
