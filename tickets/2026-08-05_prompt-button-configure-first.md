# Add "Configure first, then run" to prompt buttons

## TLDR

Hovering a prompt button reveals a secondary action "Configure first, then run" that opens the new-session page with the textarea prefilled with that prompt. Exact UI open — maybe a dropdown. Companion of #1506 (tooltips).

## Why it matters

One-click prompts are all-or-nothing today; there's no path to tweak a preset prompt before firing it.
