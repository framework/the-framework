# Add tooltips to prompt buttons

## TLDR

Prompt buttons should show a tooltip with the essentials: what's going to happen, which model will be used, where it runs (locally, CC web, ...), and possibly more. Companion of #1507 (secondary "Configure first, then run" action).

## Why it matters

Users currently click prompt buttons blind — no way to know the effect, model, or execution target before committing.
